title: بلڈ تے ونڈ
description: "npm تے TypeScript سورس، Bun ولوں چلایا، provenance نال شائع کیتا"
---

npm پیکج TypeScript سورس بھیجدا اے، کوئی بلڈ نئیں: `tokenmaxxing` bin اک Bun shebang نال سِدھا `src/main.ts` ول اشارہ کردا اے، تے Bun 1.2.6 یا اوہدے توں نواں اوہنوں جیویں دا تیویں چلاندا اے۔ ایسے لئی Bun اک سخت لوڑ اے۔ ڈزائن ولوں کوئی کمپائل کیتیاں بائنریاں نئیں: اک پہلاں والی ریلیز نے ہر پلیٹ فارم نوں اک اکلی 61 MB دی macOS بائنری بھیجی سی تے اوہ Linux تے `exec format error` نال ناکام ہو گئی، تے فی پلیٹ فارم کمپائل کیتے پیکجاں نوں ہر اک نوں اپنی ریلیز پائپ لائن دی لوڑ ہندی، سو سورس نوں Bun ولوں چلانا ای ونڈ دا ماڈل بن گیا۔

پیکج دا `exports` نقشہ `src/sdk.ts` نوں اُتے دسے پروگرامی داخلے وانگوں سامنے لیاندا اے۔ ریلیزاں GitHub تے `v<version>` نال ٹیگ کیتیاں جاندیاں نیں؛ CI trusted publishing (OIDC، provenance نال) راہیں npm تے شائع کردا اے، تے شائع کرن والا گیٹ پہلاں typecheck تے پورا ٹیسٹ سویٹ چلاندا اے۔
