---
title: 認証情報の保管と安全性モデル
description: "認証情報がプラットフォームごとにどこに存在するか、そしてすべての切り替えが強制するルール"
---

すべての状態は `~/.config/tokenmaxxing/` に存在します。認証情報の I/O は単一のプラットフォーム選択済みストアファサードを通ります。呼び出し側がプラットフォームで分岐することはありません。

**macOS**: 認証情報は Claude Code 自身が保管するのと同じ場所である、ログインキーチェーンの generic-password アイテムに存在します。ライブアイテムは claude が読むもので、プール内の各アカウントのバックアップは自身の `tokenmaxxing-cred-<uuid8>` キーチェーンアイテムとしてパークされます。ディスク上に平文のものはありません。読み取りは `security find-generic-password -w` を使い (秘密は stdout にしか現れません)、書き込みは `add-generic-password` の行を stdin 経由で `security -i` にパイプするため、秘密がどのプロセスの argv にも現れません。対話モードには約4 KB の行バッファがあるため、大きすぎる blob は argv 書き込みにフォールバックします。これがパークアイテムが最小限の OAuth オブジェクトだけを保存する理由の1つです。

**Linux**: Claude Code は認証情報を0600の平文ファイルとして保存し、tokenmaxxing も同じモデルに従います。ライブファイルは claude 自身の `.credentials.json` であり、パークバックアップは0700ディレクトリ内の `~/.config/tokenmaxxing/creds/` 下のアトミックな0600ファイルです。ここでのアトミックとは、一時ファイルへの書き込み、fsync、そしてリネームを意味します。同時実行の読み手は常に古いファイル全体か新しいファイル全体を見て、部分的なものは決して見ません。

切り替えが強制する安全ルールは次のとおりです。

- **真の所有者による取り込み。** 切り替え前に、ライブ認証情報の実際の所有者は、そのトークンがどの組織に属するかを API に問い合わせて解決されます (OAuth roles エンドポイントに対する `fetchTokenOrg`)。変動しうる保存済みのアクティブラベルを信頼することは決してありません。変動したラベルがかつて、あるアカウントの取り込みが別のアカウントの唯一のバックアップを上書きする原因になりました。ライブ認証情報がプール外のアカウントに属している場合、切り替えはそれを潰す代わりに完全に拒否します。
- **単一のクリティカルセクション。** 取り込み、新しい認証情報のインストール、そのローテートされたトークンのバックアップ、`~/.claude.json` のアカウント切り替え、アクティブラベルのコミットは、すべて同じロックされたセクション内で行われます。
- **claude 自身のリフレッシュとのインターロック。** 期限が近いセッションはいつでも自分のトークンをローテートしうるため、認証情報の書き込みは Claude Code のリフレッシュロックも取得します (ベストエフォートで、古いロックの再取得と上限付きタイムアウトを伴います)。
- **失効したグラントは正常に劣化する。** `invalid_grant` が返ってきたリフレッシュは、そのアカウントを再認証が必要としてフラグし、エラーが伝播する前にフラグを保存するため、リトライループは候補集合を縮小して終了します。`tokenmaxxing auth` はフラグされたアカウントをその場で修正し、修正対象とは別のアカウントに着地するログインを拒否します。
- **トークンのロギングなし。** トークンはログ、エラー、出力に決して現れません。トークンおよび使用量エンドポイントからのエラー本文は生のまま表に出ることはなく、許可リストに載ったフィールドのみが残ります。トークンエンドポイントの失敗本文はリクエスト内容をそのまま返すことがあるためです。
- **プローブの衛生。** 起動されるあらゆる `claude` プローブは、claude がキーチェーン参照の前に尊重する8つの環境変数 (`ANTHROPIC_API_KEY`、`CLAUDE_CODE_OAUTH_TOKEN`、`CLAUDE_SECURESTORAGE_CONFIG_DIR` など) を消去するため、プローブが誤ったアカウントに帰属されることは決してありません。
