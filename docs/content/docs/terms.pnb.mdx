title: ذاتی ورتوں تے سروسز دیاں شرطاں
description: "اپنے اکاؤنٹ اکٹھے کرو، اوہناں سیشناں تے ایجنٹاں وچ جیہڑے تُسیں آپ چلاندے او"
---

tokenmaxxing اوہ اکاؤنٹ اکٹھے کردا اے جیہڑے تہاڈے اپنے نیں، اوہناں سیشناں تے ایجنٹاں وچ جیہڑے تُسیں آپ چلاندے او۔ ایہہ لفظاں جان بُجھ کے نیں: Anthropic تیجی دھر دیاں مصنوعات نوں claude.ai لاگ اِن یا claude.ai ریٹ لِمِٹ دین دی اجازت نئیں دیندا، تے ایہدے وچ Agent SDK تے بنے ایجنٹ وی شامل نیں۔ اکٹھی کیتی SDK سطح، یا اوہدے تے بنی کوئی وی چیز، تیجی دھراں نوں نہ بھیجو۔ tokenmaxxing کوٹا ڈیٹا لئی OAuth نوں مُڑ لاگو کرن یا API ٹریفک نوں پراکسی کرن دی بجائے جان بُجھ کے CLI ذریعے والے `/usage` راہ تے وی رہندا اے: ایہہ کوئی پراکسی نئیں، تے اکو اک OAuth اینڈ پوائنٹ جیہڑے ایہہ چھیندا اے اوہ بدلاؤ دوران ورتیا جان والا معیاری refresh گرانٹ تے اک صرف پڑھن والی شناخت جانچ (roles اینڈ پوائنٹ) اے جیہڑی پکا کردی اے کہ اک ٹوکن اصل وچ کیہڑے اکاؤنٹ دا اے۔
