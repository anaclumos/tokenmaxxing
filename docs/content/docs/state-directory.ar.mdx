---
title: تخطيط دليل الحالة
description: "كل ملف ودليل تحت ~/.config/tokenmaxxing"
---

يعيش كل شيء تحت `~/.config/tokenmaxxing/` (قابل للتجاوز عبر `TOKENMAXXING_HOME`؛ ولكل مسار يمكن ملاحظته خارجيًا تجاوزٌ عبر متغيّر بيئة بحيث يمكن للأداة بأكملها أن تعمل بمعزل تام في الاختبارات).

| المسار | ما يحتويه |
|---|---|
| `config.json` | إعدادك (متناثر؛ وتُطبَّق القيم الافتراضية لكل حقل) |
| `accounts.json` | فهرس غير سرّي لحسابات Claude المُجمَّعة: التسميات والمعرّفات ونوافذ الاستخدام المخزّنة مؤقّتًا. لا رموز أبدًا |
| `usage.json` | لقطة النوافذ الإجمالية لمُوزّع سطر الحالة؛ ووقت تعديله (mtime) هو نبضة حياة التغذية |
| `model-usage.json` | حدود أسبوعية لكل نموذج مخزّنة مؤقّتًا بمدّة صلاحية من `/usage` |
| `lastswap.json` | الطابع الزمني (epoch) لآخر تبديل؛ يقود فترة التهدئة البالغة 45 ثانية |
| `depleted.json` | انتظار التجمّع المُستنفَد المسجَّل، تُعيد الخطّافات الشقيقة تشغيله حتى تمرّ إعادة الضبط، أو ينتقل المقعد العامل، أو يكتمل أي تبديل |
| `lock` | ملف `flock` الذي يسلسل عمليات التبديل |
| `serve-lock` | قفل `xx serve` الوحيد للنسخة: يُحجَب عنده جيل شيطان جديد حتى يخرج الجيل السابق بالكامل |
| `sessions/<session-id>.json` | أعلام الإطلاق لكل جلسة مُدارة يحفظها المشرف لإعادة التوليد؛ تُقلَّم بعد 30 يومًا من الخمول (بما يطابق مدّة الاحتفاظ بنسخ claude الخاصّة) |
| `tokenmaxxing.log` | سجلّ أحداث للإلحاق فقط |
| `bin/` | وسائط PATH: `claude` و`codex` ونقطتا الدخول `tokenmaxxing` / `xx` |
| `respawn/<session-id>` | علامات إعادة توليد انتظار الاستنفاد التي يترقّبها المشرف |
| `creds/` | على Linux فقط: ملفات بيانات اعتماد مُركونة، بصلاحيات 0600 في دليل بصلاحيات 0700 (يركن macOS بيانات الاعتماد بوصفها عناصر سلسلة مفاتيح لكل حساب بدلًا من ذلك) |
| `onboard/`، `sample/` | بيوت إعداد معزولة قابلة للاستهلاك لتسجيلات دخول `add`/`auth` واستطلاعات `/usage` للحسابات المُركونة؛ وتُحذَف بيوت onboard التي تحمل بيانات اعتماد نصّية صريحة بعد الجمع |
| `slack.json` | رموز `xx serve` وروابط القنوات (بصلاحيات 0600) |
| `slack-threads/` | سجلّات جلسة لكل خيط لـ `xx serve` |
| `codex-*` | تجمّع Codex الموازي: `codex-accounts.json`، و`codex-lastswap.json`، و`codex-lock`، و`codex-creds/`، و`codex-onboard/`، و`codex-respawn/`، و`codex-reconcile/` (إشارات عبر الجلسات تطلب من مشرف جلسة شقيقة إعادة التوليد على الحساب العامل)، و`codex-live/` (ملف حضور واحد مُتحقَّق من معرّف العملية (PID) لكل جلسة codex مُشرَف عليها عاملة، بحيث لا يكون الحساب العامل هدف تبديل أبدًا) |

خارج دليلها الخاص، تلمس tokenmaxxing تحديدًا: `~/.claude.json` (تبديل `oauthAccount`)، وملف `settings.json` الخاص بـ Claude Code (مدخلات الخطّاف وسطر الحالة)، ومخزن بيانات الاعتماد الحيّة (عنصر سلسلة المفاتيح `Claude Code-credentials` على macOS، و`.credentials.json` على Linux)، وأقفال تحديث claude الخاصّة به والمأخوذة أثناء عمليات التبديل (القفل الأساسي `.oauth_refresh.lock` داخل دليل إعداد claude، إضافةً إلى الشقيق القديم `~/.claude.lock`)، وملفَّي `auth.json` و`hooks.json` الخاصّين بـ codex، ووحدة الفحص الدوري في launchd أو systemd.
