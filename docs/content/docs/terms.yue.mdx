tokenmaxxing 集合你擁有嘅帳戶，喺你自己運行嘅 session 同 agent 入面使用。呢個講法係刻意嘅：Anthropic 唔容許第三方產品提供 claude.ai 登入或者 claude.ai 速率限制，當中亦包括建基於 Agent SDK 嘅 agent。唔好將集合嘅 SDK 介面，或者任何建基於佢嘅嘢，發布俾第三方。tokenmaxxing 亦都刻意行 CLI 中介嘅 `/usage` 路徑嚟攞配額數據，而唔係重新實作 OAuth 或者代理 API 流量：佢唔係代理，而佢唯一掂到嘅 OAuth 端點，就係切換期間用嘅標準刷新授權，同埋一個唯讀身分檢查（roles 端點），驗證個 token 實際上屬於邊個帳戶。
