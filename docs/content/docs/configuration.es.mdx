---
title: Configuración
description: "El esquema de config.json, los umbrales y los ajustes de política"
---

La configuración es JSON en `~/.config/tokenmaxxing/config.json`. Cada campo es opcional; los valores por defecto se aplican por campo.

```json
{
  "thresholds": { "session": 95, "weekly": 98 },
  "hardThresholds": { "session": 100, "weekly": 100 },
  "claudeBin": "/path/to/real/claude",
  "codexBin": "/path/to/real/codex",
  "policy": {
    "projectionMargin": 0,
    "greedySessionFloor": 50,
    "switchModels": ["fable"],
    "usagePollTtlMs": 90000,
    "maxWaitMs": 3600000
  }
}
```

- `thresholds.session` / `thresholds.weekly`: las barras de cribado descritas en [Cómo decide el cambio](/es/switching).
- `hardThresholds.session` / `hardThresholds.weekly`: las barras de muro (por defecto 100, el límite real del servidor de cada cuenta). Cuando cada cuenta está por encima de su barra de cribado, la decisión automática de Claude exprime cada una hasta su muro antes de estacionar - ver [El muro](/es/switching). Fija igual a `thresholds` para deshabilitarlo; Codex ignora este ajuste.
- `claudeBin` / `codexBin`: fija los binarios REALES que generan los supervisores (escritos por `init` / `init --codex`; el diagnóstico de la protección contra recursión te indica que corrijas `claudeBin` aquí cuando deje de apuntar al binario real de Claude).
- `policy.projectionMargin`: se resta tanto de las barras de cribado como de las barras de muro para formar las barras efectivas.
- `policy.greedySessionFloor`: porcentaje de sesión usado al cual entra en juego la convergencia voraz.
- `policy.switchModels`: familias de modelos cuyo tope semanal por modelo pone compuerta a un cambio (las entradas se pasan a minúsculas al cargarse).
- `policy.usagePollTtlMs`: cuánto tiempo permanece fresco un sondeo por modelo de `/usage`.
- `policy.maxWaitMs`: el límite de la espera automática por grupo agotado.

`tokenmaxxing config` muestra la configuración efectiva con sus fuentes; `config set`/`unset` editan claves con puntos; `config tidy` poda claves desconocidas.
