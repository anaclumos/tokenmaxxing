description: আপনার নিজের এজেন্ট CLI অ্যাকাউন্টগুলো একত্র করুন এবং প্রতিটি সেশন সচল রাখুন
---

tokenmaxxing হলো এমন একটি CLI যা তাদের জন্য যারা নিজেদের একাধিক অ্যাকাউন্টে Claude Code (এবং Codex) চালান। এটি ব্যবহারের কোটা নজরে রাখে, কোনো সীমায় পৌঁছানোর আগে সক্রিয় ক্রেডেনশিয়ালকে সবচেয়ে বেশি ফাঁকা থাকা অ্যাকাউন্টে বদলে দেয়, এবং বদল হওয়ার পরেও আপনার সেশনগুলো চালিয়ে যাওয়ার উপযোগী রাখে।
