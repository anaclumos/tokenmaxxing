---

اوہو اکٹھ OpenAI دی Codex CLI لئی، تہاڈے اپنے ChatGPT سبسکرپشن اکاؤنٹاں خلاف کم کردا اے:

```sh
tokenmaxxing init --codex   # اپنا موجودہ codex لاگ اِن درآمد کرو + codex سُپروائزر تے Stop ہُک انسٹال کرو
tokenmaxxing add --codex    # اک ہور اکاؤنٹ الگ تھلگ لاگ اِن کرو - تہاڈا مُکھ لاگ اِن اَن چھوہیا رہندا اے
codex                       # codex نوں ہمیشہ وانگوں ورتو
```

Codex پول پوری طرحاں نال نال چلدی حالت اے: اپنا اکاؤنٹ اِنڈیکس، اپنیاں پارک کیتیاں کریڈینشل فائلاں (دوواں پلیٹ فارماں تے 0600 فائلاں، کیوں جو codex دا اپنا سٹور اک سادہ لکھت فائل اے)، اپنا لاک، اپنا چھیکڑلا بدلاؤ ٹائم سٹیمپ۔ فیصلہ پالیسی کوڈ توں بغیر Claude پول نال کجھ وی ساجھا نئیں۔

## Codex تے ہاٹ سویپ کیوں ناممکن اے

اک چلدا codex پروسیس اک اِن میموری auth منیجر رکھدا اے تے صاف صاف `auth.json` نوں مُڑ لوڈ کرن توں انکار کر دیندا اے جدوں اوہ ہُنے کسے وکھرے اکاؤنٹ دا ناں دسے۔ کوئی فائل واچر تے کوئی فی بینتی کریڈینشل پول نئیں، سو اک چلدے codex دے تھلے بدلیا کریڈینشل اِنفرینس لئی کدے اثر ای نئیں کردا۔ مُڑ چالو کرنا ای بدلاؤ اے: `codex resume <session-id>` اوس اکاؤنٹ تے مقامی ٹرانسکرپٹ نوں جاری رکھدا اے جیہڑا `auth.json` ہُنے رکھدا اے۔

tokenmaxxing ایہنوں اک codex سُپروائزر شِم نال سنبھالدا اے: Stop ہُک ہر ٹرن حد تے اوہو لالچی رفتار دباؤ فیصلہ چلاندا اے، تے جدوں اوہ بدلدا اے، اوہ اک مارکر لکھدا اے جیہڑا سُپروائزر نوں پکی حد تے سیشن نوں SIGTERM کرن تے تازہ اکاؤنٹ تے `codex resume <session-id>` مُڑ لانچ کرن لان دیندا اے، ٹرانسکرپٹ سلامت۔ کیوں جو ہر codex بدلاؤ اک نظر آن والا مُڑ چالو اے، codex لالچی راہ اک 1.2x بہتری مارجن رکھدی اے: اک چیلنجر نوں موجودہ اکاؤنٹ دے رفتار دباؤ نوں 20% نال ہرانا پیندا اے، وال جِنے نال نئیں۔ سخت راہ (اک پار کیتی بار) مارجن نوں نظر انداز کردی اے۔ codex لئی کوئی مُکے پول دی اُلٹی گنتی وی نئیں - کجھ وی codex سیشن نوں نئیں روک سکدا - سو اک پوری طرحاں مُکی codex پول اوتھے ای رہندی اے۔

ہور codex لئی خاص طریقہ کار:

- ورتوں codex دے اپنے ریٹ لِمِٹ اینڈ پوائنٹ خلاف اک مفت تصدیق شدہ GET توں پڑھی جاندی اے (اوہو کال جیہڑی CLI دا `/status` کردا اے): فیصد نال مطلق ایپاک ری سیٹ ویلے، کُل جوڑ ونڈواں تے فی ماڈل حداں دوویں۔ ونڈو دی درجہ بندی مدت مطابق ہندی اے، کدے تھاں مطابق نئیں، کیوں جو موجودہ پلاناں دی شاید کوئی 5 گھنٹے دی ونڈو ای نہ ہووے تے ہفتہ وار ونڈو مُکھ سلاٹ وچ بیٹھی ہوندی اے۔
- Codex refresh ٹوکن گھمدے نیں، تے اک بدلے گئے ٹوکن نوں مُڑ ورتنا سارے گرانٹ خاندان نوں مار دیندا اے۔ ہر گھماؤ اوہدے واپس آندے ای محفوظ کر لیا جاندا اے، چالو اکاؤنٹ دا نمونہ صرف لائیو بلاب راہیں ای لیا جاندا اے (کدے کوئی باسی پارک کیتی نقل نئیں)، تے فی سیشن موجودگی فائلاں یقینی بناندیاں نیں کہ اک اکاؤنٹ جیہڑا کسے لائیو نال دے سیشن وچ چل رہیا ہووے اوہ کدے بدلاؤ دا نشانہ نئیں تے اوہدا پارک کیتا ٹوکن کدے refresh نئیں ہندا۔
- Codex نوں فائل کریڈینشل سٹور چاہیدا: جے keyring سٹور پِن ہووے تاں `init --codex` چھیتی ناکام ہو جاندا اے، تے `add --codex` فائل موڈ سیٹنگ نوں الگ تھلگ آن بورڈنگ ہوم وچ لکھدا اے تاں جو لاگ اِن سمیٹن جوگا اپڑے۔
- اک ہتھیں قدم: codex اوہناں ہُکاں نوں چھڈ دیندا اے جنہاں تے بھروسہ کرن لئی اوہنوں نئیں کیہا گیا۔ `init --codex` توں بعد، codex اک وار کھولو تے `/hooks` راہیں tokenmaxxing Stop ہُک تے بھروسہ کرو، نہیں تاں خودکار بدلی چُپ چاپ بے حرکت رہندی اے۔ `init --codex` ایہہ یاد دہانی چھاپدا اے۔
