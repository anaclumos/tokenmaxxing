الإعدادات JSON في `~/.config/tokenmaxxing/config.json`. كل حقل اختياري؛ القيم الافتراضية بتتطبّق لكل حقل.

```json
{
  "thresholds": { "session": [90], "weekly": 98 },
  "hardThresholds": { "session": 100, "weekly": 100 },
  "claudeBin": "/path/to/real/claude",
  "codexBin": "/path/to/real/codex",
  "policy": {
    "projectionMargin": 0,
    "greedySessionFloor": 80,
    "switchModels": ["fable"],
    "usagePollTtlMs": 90000,
    "maxWaitMs": 3600000
  }
}
```

- `thresholds.session`: سلّم الـ 5 ساعات، قايمة صاعدة من درجات الفرز. كل تقييم بيحدّد درجة نشطة واحدة، أوطى درجة لسه فيه حساب في الـ pool قابل للاستخدام عندها، والدرجة دي هي الزناد وفرز المرشحين في نفس الوقت. Codex بيقرا الدرجة الأعلى بس. بص [إزاي التبديل بيتقرر](/arz/switching).
- `thresholds.weekly`: شرط الفرز الأسبوعي، وبيغطّي الإجمالي بتاع الـ 7 أيام وكل حد أسبوعي لكل موديل.
- `hardThresholds.session` / `hardThresholds.weekly`: شرايط الحائط (الافتراضي 100، الحد الحقيقي على السيرفر لكل حساب). لازم `hardThresholds.session` يبقى عند الدرجة الأعلى للـ session أو فوقها. لما كل حساب يبقى فوق شرط الفرز بتاعه، قرار Claude التلقائي بيعصر كل واحد لغاية حائطه قبل ما يركنه - بص [الحائط](/arz/switching). اضبطها تساوي الدرجة الأعلى والشرط الأسبوعي عشان تعطّلها؛ Codex بيتجاهل الإعداد ده.
- `claudeBin` / `codexBin`: بيثبّتوا على الـ binaries الحقيقية اللي الـ supervisors بتشغّلها (بتتكتب من `init` / `init --codex`؛ تشخيص حارس التكرار بيقولك تصلّح `claudeBin` هنا لما يبطّل يشاور على الـ Claude binary الحقيقي).
- `policy.projectionMargin`: بيتطرح من كل درجة session، ومن الشرط الأسبوعي، ومن شرايط الحائط عشان يكوّن الشرايط الفعّالة.
- `policy.greedySessionFloor`: نسبة استخدام الـ session اللي عندها التقارب الـ greedy بينخرط.
- `policy.switchModels`: عيلات الموديلات اللي حدها الأسبوعي لكل موديل بيبوّب التبديل (المدخلات بتتحول لحروف صغيرة عند التحميل).
- `policy.usagePollTtlMs`: قد إيه الـ poll بتاع `/usage` لكل موديل بيفضل حديث.
- `policy.maxWaitMs`: حد الانتظار التلقائي للـ pool المستنفد.

`tokenmaxxing config` بيوريّك الإعدادات الفعّالة مع مصادرها؛ `config set`/`unset` بيعدّلوا المفاتيح المنقّطة؛ `config tidy` بيشيل المفاتيح المجهولة.
