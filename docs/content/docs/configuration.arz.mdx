الإعدادات JSON في `~/.config/tokenmaxxing/config.json`. كل حقل اختياري؛ القيم الافتراضية بتتطبّق لكل حقل.

```json
{
  "thresholds": { "session": 95, "weekly": 98 },
  "hardThresholds": { "session": 100, "weekly": 100 },
  "claudeBin": "/path/to/real/claude",
  "codexBin": "/path/to/real/codex",
  "policy": {
    "projectionMargin": 0,
    "greedySessionFloor": 50,
    "switchModels": ["fable"],
    "usagePollTtlMs": 90000,
    "maxWaitMs": 3600000
  }
}
```

- `thresholds.session` / `thresholds.weekly`: شرايط الفرز الموصوفة في [إزاي التبديل بيتقرر](/arz/switching).
- `hardThresholds.session` / `hardThresholds.weekly`: شرايط الحائط (الافتراضي 100، الحد الحقيقي على السيرفر لكل حساب). لما كل حساب يبقى فوق شرط الفرز بتاعه، القرار التلقائي بيعصر كل واحد لغاية حائطه قبل ما يركنه - بص [الحائط](/arz/switching). اضبطها تساوي `thresholds` عشان تعطّلها.
- `claudeBin` / `codexBin`: بيثبّتوا على الـ binaries الحقيقية اللي الـ supervisors بتشغّلها (بتتكتب من `init` / `init --codex`؛ تشخيص حارس التكرار بيقولك تصلّح `claudeBin` هنا لما يبطّل يشاور على الـ Claude binary الحقيقي).
- `policy.projectionMargin`: بيتطرح من شرايط الفرز وشرايط الحائط الاتنين عشان يكوّن الشرايط الفعّالة.
- `policy.greedySessionFloor`: نسبة استخدام الـ session اللي عندها التقارب الـ greedy بينخرط.
- `policy.switchModels`: عيلات الموديلات اللي حدها الأسبوعي لكل موديل بيبوّب التبديل (المدخلات بتتحول لحروف صغيرة عند التحميل).
- `policy.usagePollTtlMs`: قد إيه الـ poll بتاع `/usage` لكل موديل بيفضل حديث.
- `policy.maxWaitMs`: حد الانتظار التلقائي للـ pool المستنفد.

`tokenmaxxing config` بيوريّك الإعدادات الفعّالة مع مصادرها؛ `config set`/`unset` بيعدّلوا المفاتيح المنقّطة؛ `config tidy` بيشيل المفاتيح المجهولة.
