---
title: 配置
description: "config.json 嗰结构、阈值搭策略旋钮。"
---

配置是勒 `~/.config/tokenmaxxing/config.json` 嗰 JSON。每个字段侪是可选嗰；默认值一个字段一个字段生效。

```json
{
  "thresholds": { "session": 95, "weekly": 98 },
  "hardThresholds": { "session": 100, "weekly": 100 },
  "claudeBin": "/path/to/real/claude",
  "codexBin": "/path/to/real/codex",
  "policy": {
    "projectionMargin": 0,
    "greedySessionFloor": 50,
    "switchModels": ["fable"],
    "usagePollTtlMs": 90000,
    "maxWaitMs": 3600000
  }
}
```

- `thresholds.session` / `thresholds.weekly`：[切换是哪能决定嗰](/wuu/switching)里向讲过嗰筛选阈值。
- `hardThresholds.session` / `hardThresholds.weekly`：墙壁阈值（默认 100，是每个账户真嗰服务器限额）。等每个账户侪超过伊嗰筛选阈值嗰辰光，自动决策会先拿每个账户挤到伊嗰墙壁为止，然后再停放，看 [墙壁](/wuu/switching)。设成搭 `thresholds` 相等就好禁脱。
- `claudeBin` / `codexBin`：钉牢 supervisor 起动嗰真身二进制（勒 `init` / `init --codex` 辰光写落嗰；辰光递归防护嗰诊断讲侬去修 `claudeBin`，就是伊勿再指牢真嗰 Claude 二进制嗰辰光）。
- `policy.projectionMargin`：从筛选阈值搭墙壁阈值里向侪减脱，得出有效阈值。
- `policy.greedySessionFloor`：贪心收敛开始运作嗰会话已用百分比。
- `policy.switchModels`：哪几个模型系列嗰分模型礼拜上限会给切换把关（条目加载嗰辰光会转成小写）。
- `policy.usagePollTtlMs`：一趟 `/usage` 分模型轮询保持新鲜多少辰光。
- `policy.maxWaitMs`：耗光池子自动等待嗰上限。

`tokenmaxxing config` 显示带来源嗰有效配置；`config set`/`unset` 编辑带点嗰键；`config tidy` 剪脱勿认得嗰键。
