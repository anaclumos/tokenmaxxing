title: వ్యక్తిగత వినియోగం మరియు సేవా నిబంధనలు
description: "మీకు స్వంతమైన ఖాతాలను, మీరే నడిపే సెషన్‌లు మరియు ఏజెంట్‌లలో పూల్ చేయండి"
---

tokenmaxxing మీకు స్వంతమైన ఖాతాలను, మీరే నడిపే సెషన్‌లు మరియు ఏజెంట్‌లలో పూల్ చేస్తుంది. ఆ పదజాలం ఉద్దేశపూర్వకమైనది: మూడవ-పక్ష ఉత్పత్తులు claude.ai లాగిన్ లేదా claude.ai రేట్ పరిమితులను అందించడానికి Anthropic అనుమతించదు, మరియు అందులో Agent SDKపై నిర్మించిన ఏజెంట్‌లు కూడా ఉన్నాయి. పూల్ చేసిన SDK ఉపరితలాన్ని, లేదా దానిపై నిర్మించిన దేనినైనా మూడవ పక్షాలకు రవాణా చేయవద్దు. tokenmaxxing OAuthను తిరిగి అమలు చేయడం లేదా API ట్రాఫిక్‌ను ప్రాక్సీ చేయడం కంటే కోటా డేటా కోసం CLI-మధ్యవర్తిత్వ `/usage` మార్గంపైనే ఉద్దేశపూర్వకంగా ఉంటుంది: ఇది ప్రాక్సీ కాదు, మరియు ఇది తాకే ఏకైక OAuth ఎండ్‌పాయింట్‌లు మార్పిడి సమయంలో ఉపయోగించే ప్రామాణిక రిఫ్రెష్ గ్రాంట్ మరియు ఒక టోకెన్ నిజంగా ఏ ఖాతాకు చెందుతుందో ధృవీకరించే చదవడం-మాత్రమే గుర్తింపు తనిఖీ (roles ఎండ్‌పాయింట్).
