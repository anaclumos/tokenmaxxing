tokenmaxxing هو CLI للناس اللي بيشغّلوا Claude Code (و Codex) على كذا حساب من حساباتهم. بيراقب حصص الاستخدام، وبيبدّل الـ credential النشط للحساب اللي عنده أكبر مساحة فاضية قبل ما يوصل لأي حد، وبيخلّي الـ sessions بتاعتك تقدر تكمّل عبر التبديلات.
