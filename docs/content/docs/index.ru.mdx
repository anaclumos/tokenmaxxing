tokenmaxxing - это CLI для тех, кто запускает Claude Code (и Codex) на нескольких собственных аккаунтах. Он следит за квотами использования, переключает активные учётные данные на аккаунт с наибольшим запасом, прежде чем будет достигнут лимит, и позволяет продолжать сессии после переключений.
