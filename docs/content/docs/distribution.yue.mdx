description: "npm 同 Nix 上嘅 TypeScript 原始碼，由 Bun 運行，帶來源證明發布"
---

npm 套件發布嘅係 TypeScript 原始碼，而唔係 build：`tokenmaxxing` bin 用 Bun shebang 直接指向 `src/main.ts`，而 Bun 1.2.6 或以上版本會原封不動咁行。呢個就係點解 Bun 係硬性要求。刻意冇編譯二進位檔：早期有個版本將同一個 61 MB 嘅 macOS 二進位檔發布到每個平台，喺 Linux 上就報 `exec format error` 失敗咗，而每個平台嘅編譯套件各自都要有自己嘅發布流水線，所以由 Bun 運行原始碼就成為咗分發模型。

套件嘅 `exports` 映射將 `src/sdk.ts` 公開成 [Agent SDK 介面](/yue/sdk)入面描述嘅程式化入口。發布版本喺 GitHub 上會標記做 `v<version>`。CI 會透過受信任發布（OIDC，連同來源證明）發布到 npm，而發布閘門會先跑類型檢查同完整嘅測試套件。

## Nix／nix-darwin

同一棵源碼樹同時都係一個 flake。佢仍然跟住「用 Bun 直接跑源碼」嗰套（經 [bun2nix](https://github.com/nix-community/bun2nix) 嘅 `writeBunApplication`），同埋公開：

| 輸出 | 用途 |
|---|---|
| `packages.default` | 將 `tokenmaxxing` 同 `xx` 放落 PATH |
| `darwinModules.default` / `withOverlay` | nix-darwin：裝 CLI（可選嘅聲明式檢查計時器） |
| `homeManagerModules.default` | macOS 或者 Linux 嘅 Home Manager |
| `nixosModules.default` / `withOverlay` | NixOS 系統級安裝 |

唔使裝入 profile，即場跑一次：

```sh
nix run github:anaclumos/tokenmaxxing -- help
```

nix-darwin（加埋 overlay，等 `pkgs.tokenmaxxing` 解到）：

```nix
{
  inputs.tokenmaxxing.url = "github:anaclumos/tokenmaxxing";
  # ...
  modules = [
    inputs.tokenmaxxing.darwinModules.withOverlay
    { programs.tokenmaxxing.enable = true; }
  ];
}
```

又或者明確指定個 package（Home Manager 都用得）：

```nix
{
  imports = [ inputs.tokenmaxxing.homeManagerModules.default ];
  programs.tokenmaxxing.enable = true;
  programs.tokenmaxxing.package = inputs.tokenmaxxing.packages.${pkgs.system}.default;
}
```

Nix 淨係將 CLI 放落 PATH。帳戶匯入、PATH 上面嘅 `claude` supervisor shim、`settings.json` 嘅 hook，同埋（預設）定期檢查計時器，仍然嚟自 `tokenmaxxing init`——呢啲會掂到憑證同用戶自己嘅設定，一個純模組唔應該改寫。只有你想計時器由 Nix 管、而唔係 init 嗰陣，先至設 `programs.tokenmaxxing.checkTimer.enable = true`。

`bun.lock` 有變就重新產生 Nix 依賴表達式：

```sh
bun run nix:bun   # writes bun.nix via bun2nix
```
