title: فوری آغاز
description: "tokenmaxxing انسٹال کریں، اپنا موجودہ اکاؤنٹ امپورٹ کریں، اور مزید پول کریں"
---

macOS یا Linux پر [Bun](https://bun.sh) اور Claude Code درکار ہیں۔ Bun سے انسٹال کریں، یا اگر آپ پہلے سے Nix / nix-darwin استعمال کرتے ہیں تو flake سے۔ `init` سے پہلے CLI کو PATH پر لے آئیں (دیکھیں [بلڈ اور تقسیم](/ur/distribution)):

```sh
bun add -g tokenmaxxing
tokenmaxxing init
```

Nix استعمال کرنے والے Bun والے مرحلے کی جگہ `nix profile install github:anaclumos/tokenmaxxing` چلاتے ہیں، یا اپنی nix-darwin یا Home Manager کنفیگ میں `programs.tokenmaxxing` فعال کرتے ہیں۔

`init` پانچ کام کرتا ہے:

1. جس اکاؤنٹ سے آپ پہلے ہی لاگ اِن ہیں اسے اکاؤنٹ #1 کے طور پر امپورٹ کرتا ہے (کوئی الگ `adopt` کمانڈ نہیں ہے)۔
2. `claude` سپروائزر شِم انسٹال کرتا ہے۔
3. Claude Code کی `settings.json` میں چار اندراجات انسٹال کرتا ہے: ایک statusLine، ایک Stop ہک، ایک StopFailure ہک، اور ایک SessionStart ہک (نیز ایک subagentStatusLine اندراج)۔
4. سپروائزر کی bin ڈائرکٹری کو آپ کے شیل rc کے PATH میں شامل کرتا ہے (idempotent، ایک `# tokenmaxxing PATH` تبصرے سے نشان زد)۔ اسے اصل `claude` سے پہلے PATH پر بیٹھنا پڑتا ہے تاکہ اسے روک سکے۔
5. ایک وقفہ وار چیک ٹائمر انسٹال کرتا ہے (macOS پر ایک launchd ایجنٹ، Linux پر ایک systemd یوزر ٹائمر) جو ہر ٹِک پر ایک بار `tokenmaxxing check --if-due` چلاتا ہے (`policy.checkIntervalMs`، پہلے سے طے شدہ 60 سیکنڈ)؛ چیک لائیو اکاؤنٹ کی گنجائش دیکھ کر اپنی رفتار خود ایک سے پانچ ٹِک کے درمیان طے کرتا ہے۔

اپنے شیل کو دوبارہ شروع کریں، پھر مزید اکاؤنٹس شامل کریں اور آگے بڑھیں:

```sh
tokenmaxxing add        # ایک اور اکاؤنٹ کو الگ تھلگ حالت میں لاگ اِن کر کے پول میں شامل کرتا ہے
claude                  # claude کو ہمیشہ کی طرح استعمال کریں
```

`tokenmaxxing` کا عرف `xx` بھی ہے۔ خالی `tokenmaxxing` (یا `xx`) `status` چلاتا ہے؛ `switch` واضح طور پر لکھنا لازم رہتا ہے۔
