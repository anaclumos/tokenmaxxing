---
title: 設定
description: "config.json 嘅 schema、閾值同策略選項"
---

設定係一份 JSON，放喺 `~/.config/tokenmaxxing/config.json`。每個欄位都係可選；預設值會逐個欄位套用。

```json
{
  "thresholds": { "session": 95, "weekly": 98 },
  "policy": {
    "projectionMargin": 0,
    "greedySessionFloor": 50,
    "switchModels": ["fable"],
    "usagePollTtlMs": 90000,
    "maxWaitMs": 3600000
  }
}
```

- `thresholds.session` / `thresholds.weekly`：上面描述嘅篩選界線。
- `policy.projectionMargin`：會喺兩條界線各自減走，得出有效界線。
- `policy.greedySessionFloor`：session 已用百分比去到幾多，貪婪收斂就會啟動。
- `policy.switchModels`：每模型每週上限會閘住切換嘅模型系列（載入時項目會轉做細楷）。
- `policy.usagePollTtlMs`：`/usage` 每模型輪詢保持新鮮嘅時間。
- `policy.maxWaitMs`：帳戶池耗盡時自動等待嘅上限。

`tokenmaxxing config` 會顯示連同來源嘅有效設定；`config set`/`unset` 編輯點分隔嘅 key；`config tidy` 刪走未知嘅 key。
