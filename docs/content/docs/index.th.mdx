tokenmaxxing เป็น CLI สำหรับการสลับบัญชี Claude Code แบบอัตโนมัติ โดยจะรวมบัญชีแบบ subscription (Pro/Max) หลายบัญชีที่คุณเป็นเจ้าของ และ hot-swap credential ที่ใช้งานอยู่ไปยังบัญชีที่สดกว่าเมื่อบัญชีที่กำลังใช้อยู่ใกล้ถึงลิมิตการใช้งาน คุณยังคงรัน `claude` ได้เหมือนเดิมทุกอย่าง การสลับจะเกิดขึ้นที่ขอบเขตของเทิร์นที่ปลอดภัย และเซสชันที่กำลังทำงานอยู่ของคุณจะดำเนินบทสนทนาเดิมต่อไปบนบัญชีใหม่โดยไม่ต้องรีสตาร์ท ระบบนี้ทำงานได้กับหลายเซสชันที่ทำงานพร้อมกันในคราวเดียว

พฤติกรรมเดียวที่คุณจะเห็นคือกรณีที่แย่ที่สุด นั่นคือเมื่อทั้งพูล (pool) ถึงลิมิตหมดแล้ว เซสชันจะหยุดชั่วคราวพร้อมกับนับถอยหลัง และกลับมาทำงานต่อโดยอัตโนมัติบนบัญชีถัดไปที่รีเซ็ต (กด Ctrl-C เพื่อกลับมาทำงานต่อทันที)

<Callout>
ขอบเขต: Claude Code บน macOS และ Linux รวมถึง Codex CLI ของ OpenAI ในฐานะพูลที่สองที่ทำงานคู่ขนานกัน เครื่องมือนี้รวมบัญชีแบบ subscription ไม่ใช่ API key นี่เป็นเครื่องมือสำหรับการใช้งานส่วนตัวเพื่อรวมบัญชีที่คุณเป็นเจ้าของ ในเซสชันและ agent ที่คุณรันเอง ดู [การใช้งานส่วนตัวและข้อกำหนดในการให้บริการ](/th/terms)
</Callout>

## ปัญหา

subscription ของ Claude มีการวัดลิมิตสามอย่างพร้อมกัน (ทั้งหมดยืนยันผ่าน `/usage`):

- **เซสชันปัจจุบัน**: หน้าต่างเวลาแบบเลื่อน (rolling) 5 ชั่วโมง
- **สัปดาห์ปัจจุบัน (ทุกโมเดล)**: ยอดรวม 7 วัน
- **สัปดาห์ปัจจุบัน แยกตามโมเดล**: ลิมิตรายสัปดาห์แยกต่างหากสำหรับแต่ละตระกูลโมเดล ปัจจุบันมีเฉพาะ Sonnet และ Fable เท่านั้น และมีเพียงลิมิตของ Fable ที่แน่นพอที่จะมีผลจริง โดยจะถึงลิมิตก่อนยอดรวมมาก เครื่องอาจอยู่ที่ 50% ของ week-all ในขณะที่อยู่ที่ 80% ของ week-Fable แล้ว

โควตารายสัปดาห์เป็นแบบใช้หรือเสีย (use-it-or-lose-it) นั่นคือส่วนที่บัญชียังไม่ได้ใช้เมื่อถึงเวลารีเซ็ตรายสัปดาห์แบบตายตัวจะถูกริบไป ถ้าคุณเป็นเจ้าของบัญชีหลายบัญชี กลยุทธ์ที่สมเหตุสมผลคือใช้โควตาต่อไปบนบัญชีที่ล้าหลังจังหวะรายสัปดาห์ของตัวเองมากที่สุด และสลับออกไปก่อนที่ลิมิตใดลิมิตหนึ่งจะชนกำแพงกลางเซสชัน

การทำสิ่งนั้นด้วยมือหมายถึงต้องออกจากระบบ เข้าสู่ระบบใหม่ และสูญเสียบทสนทนาของคุณ tokenmaxxing ทำสิ่งนี้ให้อัตโนมัติ กล่าวคือ `claude` ที่กำลังทำงานอยู่จะตรวจสอบที่เก็บ credential ของมันอีกครั้งระหว่างคำขอต่างๆ ดังนั้น credential ที่ถูกสลับอยู่ข้างใต้จึงถูกนำมาใช้แทนที่ได้ทันที (ภายในประมาณ 30 วินาทีบน macOS และในคำขอถัดไปบน Linux) การสลับแบบธรรมดาจะไม่รีสตาร์ทเซสชันของคุณเลย กรณีเดียวที่ยังต้องมีการจัดการโปรเซสคือเมื่อพูลหมดเกลี้ยงทั้งพูล เพราะเซสชันไม่สามารถหยุดตัวเองได้ และนั่นคือเหตุผลที่ตัว supervisor แบบบางเบามีอยู่

ทุกอย่างที่เหลือเกี่ยวกับ `claude` ยังคงเหมือนเดิม ไม่ว่าจะเป็นแฟล็กทั้งหมด เซิร์ฟเวอร์ MCP ฮุก และสกิล ล้วนส่งผ่านไปได้ตามปกติ
