---
title: ยินดีต้อนรับ
description: รวมบัญชี agent CLI ของคุณเองและทำให้ทุกเซสชันเดินหน้าต่อไปได้
---

tokenmaxxing เป็น CLI สำหรับผู้ที่ใช้ Claude Code (และ Codex) บนบัญชีของตัวเองหลายบัญชี โดยจะคอยตรวจสอบโควตาการใช้งาน สลับ credential ที่ใช้งานอยู่ไปยังบัญชีที่มีพื้นที่เหลือมากที่สุดก่อนที่จะถึงลิมิต และทำให้เซสชันของคุณดำเนินต่อไปได้แม้จะมีการสลับ
