tokenmaxxing 是一款面向在多个自有账户上运行 Claude Code（以及 Codex）的用户的 CLI 工具。它会监控用量配额，在触及限额之前把活动凭证切换到余量最多的账户，并让你的会话在多次切换之间保持可继续。
