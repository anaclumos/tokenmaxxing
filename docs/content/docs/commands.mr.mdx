---
title: कमांड्स
description: "प्रत्येक tokenmaxxing कमांड आणि ती काय करते"
---

| कमांड | ती काय करते |
|---|---|
| `tokenmaxxing init` | सध्याचे खाते आयात करा, पर्यवेक्षक, हुक्स आणि statusline स्थापित करा |
| `tokenmaxxing init --codex` | Codex साठी तेच: लॉगिन आयात करा, codex पर्यवेक्षक आणि Stop हुक स्थापित करा |
| `tokenmaxxing add` | अतिरिक्त खाते नोंदवा (वेगळे लॉगिन, पूलमध्ये संकलित) |
| `tokenmaxxing add --codex` | अतिरिक्त Codex खाते नोंदवा (वेगळे लॉगिन) |
| `tokenmaxxing auth [sel \| --all]` | पूलमधील खाते जागच्या जागी पुन्हा प्रमाणित करा. साधा पूलची यादी करतो आणि कोणते ते विचारतो; निवडक एका खात्याला लक्ष्य करतो आणि कोणत्या ईमेलने साइन इन करायचे ते सांगतो; `--all` प्रत्येक पुन्हा-प्रमाणीकरण-आवश्यक खात्यातून एकेक करून जातो |
| `tokenmaxxing switch [sel]` | सर्वोत्तम खात्यावर बदला (हावरट, आयडेम्पोटेंट) किंवा विशिष्ट खाते सक्ती करा |
| `tokenmaxxing switch --codex [sel]` | Codex पूल बदला (पुढील codex सुरुवातीला लागू होतो) |
| `tokenmaxxing ls` | पूलमधील खात्यांची यादी करा |
| `tokenmaxxing status` | ५तास / साप्ताहिक / प्रति-मॉडेल वापर बारसह खाती, सक्रिय आणि रीसेटपर्यंत संपलेली |
| `tokenmaxxing status --force` | अतिरिक्तपणे प्रत्येक खात्याला पिंग करा (प्रत्येकी एक लहान haiku विनंती) जेणेकरून सर्व ५तासांचे सत्र टायमर आता सुरू होतील, नंतर ताजे नमुने घ्या |
| `tokenmaxxing watch [seconds]` | थेट स्थिती, दर N सेकंदांनी पुन्हा प्रस्तुत केली जाते (डीफॉल्ट १२०, किमान ३०; कधीही पिंग करत नाही) |
| `tokenmaxxing config [get\|set\|unset\|tidy]` | स्रोतांसह प्रभावी कॉन्फिग; डॉट-केलेल्या कीज संपादित करा; `tidy` अज्ञात कीज काढून टाकते |
| `tokenmaxxing check` | बदल निर्णयाचे एकदा मूल्यांकन करा (हेच नियतकालिक टायमर चालवतो) |
| `tokenmaxxing serve [setup\|link\|unlink\|links]` | Slack ब्रिज डिमन (Socket Mode, सार्वजनिक URL नाही) |
| `tokenmaxxing doctor` | पर्यवेक्षक आणि सेटिंग्ज नोंदी टिकून राहिल्याची पडताळणी करा |
| `tokenmaxxing rename [--codex] <sel> <label>` | पूलमधील खात्याचे नाव पुन्हा द्या |
| `tokenmaxxing rm [--codex] <sel>` | claude किंवा codex पूलमधून खाते (आणि त्याचे पार्क केलेले क्रेडेन्शियल) काढा |
| `tokenmaxxing uninstall` | पर्यवेक्षक आणि सेटिंग्ज नोंदी काढा (खाती आणि क्रेडेन्शियल्स ठेवले जातात) |
