description: तुमची स्वतःची एजंट CLI खाती एकत्र करा आणि प्रत्येक सत्र सुरू ठेवा
---

tokenmaxxing हे अशा लोकांसाठी एक CLI आहे जे Claude Code (आणि Codex) त्यांच्या स्वतःच्या अनेक खात्यांवर चालवतात. ते वापर कोटा पाहते, मर्यादा गाठण्यापूर्वी सक्रिय क्रेडेन्शियल सर्वात जास्त मोकळीक असलेल्या खात्यावर बदलते, आणि बदलांदरम्यान तुमची सत्रे सुरू ठेवण्यायोग्य ठेवते.
