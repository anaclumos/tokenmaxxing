title: Maligayang pagdating
description: I-pool ang iyong sariling mga account sa agent CLI at panatilihing gumagalaw ang bawat session
---

Ang tokenmaxxing ay isang CLI para sa mga taong nagpapatakbo ng Claude Code (at Codex) sa ilan sa kanilang sariling mga account. Binabantayan nito ang mga usage quota, ipinapalit ang aktibong credential sa account na may pinakamalaking puwang bago tumama ang isang limitasyon, at pinananatiling maaaring ipagpatuloy ang iyong mga session sa kabila ng mga pagpapalit.
