---
title: سچیاں حداں
description: "اکٹھی کیتی ہاٹ سویپنگ نال آن والے سمجھوتے"
---

- **اک ٹھنڈا ٹرن۔** پرامپٹ کیش تنظیم دے دائرے وچ اے، سو نویں اکاؤنٹ تے پہلا ٹرن سیاق نوں اک وار مُڑ اپ لوڈ کردا اے۔
- **مُکن دی روک دی ہچکی۔** صرف اک پوری طرحاں مُکی پول ای سیشن نوں اُلٹی گنتی لئی روکدی اے؛ اوس پل وچ ٹائپ کیتی کوئی وی چیز گواچ جاندی اے۔
- **اپنائے جان دی دیر۔** macOS تے اک بدلاؤ دے ~30 سیکنڈ اندر پہلا ٹرن ہالی وی پرانے اکاؤنٹ نوں گِن سکدا اے؛ باراں دی گنجائش ایہنوں جذب کر لیندی اے۔
- **ساجھا دھماکے دا گھیرا۔** سارے طے شدہ پروفائل سیشن اک لائیو کریڈینشل ساجھا کردے نیں، سو اک بدلاؤ اوہناں ساریاں نوں اکٹھیاں ہلاندا اے (ہر اک اوتھے ای اپناندا اے)۔
- **Linux تے سادہ لکھت کریڈینشل۔** Claude Code آپ Linux کریڈینشل نوں اک 0600 سادہ لکھت فائل وانگوں رکھدا اے؛ tokenmaxxing دیاں پارک کیتیاں نقلاں اوہو ماڈل اپناندیاں نیں۔
- **اک میزبان تے اک پول۔** کئی مشیناں تے اکو اکاؤنٹاں نوں پول کرنا کم کردا اے، پر ہر میزبان اپنے طور تے ٹوکن پارک تے گھمانداں اے، کوئی کراس-میزبان لاک نئیں: دو میزبان اکو اکاؤنٹ دا ٹوکن اکٹھے ای refresh کردے تاں دوڑ لگ جاندی اے۔ Claude تے، refresh دی گھمائی پہلے والے access ٹوکن نوں فوراً رد کر دیندی اے، سو دوجے میزبان دے سیشن 401 نال ناکام ہو جاندے نیں تے اوہدا باسی refresh ٹوکن `invalid_grant` بن کے موڑ آندا اے (مُڑ تصدیق دی لوڑ)۔ Codex لئی پرانی پارک کیتی نقل توں refresh اوس لاگ اِن لئی جان لیوا اے (OpenAI refresh-token دوبارہ ورتن تے پوری grant فیملی رد کر دیندا اے، ہر میزبان تے `auth` مجبور کردا اے)۔ جے تُسیں کوئی اکاؤنٹ اک توں زیادہ مشین تے پول کردے او، تاں Claude تے re-auth دی کھپ متوقع رکھو تے Codex لئی ایہدے توں بالکل بچو۔
