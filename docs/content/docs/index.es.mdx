tokenmaxxing es una CLI para quienes ejecutan Claude Code (y Codex) en varias de sus propias cuentas. Vigila las cuotas de uso, cambia la credencial activa a la cuenta con más margen antes de que se alcance un límite y mantiene tus sesiones continuables entre cambios.
