title: "Slack پُل: xx serve"
description: "xx serve Socket Mode راہیں Slack تھریڈاں توں Claude Code سیشن چلاندا اے"
---

`tokenmaxxing serve` Socket Mode راہیں اک مقامی Slack ڈیمن چلاندا اے - کسے عوامی URL دی لوڑ نئیں۔ سیٹ اپ:

```sh
tokenmaxxing serve setup                    # ایپ مینی فیسٹ چھاپدا اے، دو ٹوکناں لئی پُچھدا اے
tokenmaxxing serve link <channel-id> <repo> # اک چینل نوں اک repo چیک آؤٹ نال جوڑو
tokenmaxxing serve                          # ڈیمن چلاؤ
```

کسے جُڑے چینل وچ بوٹ نوں مینشن کرو تے اوہ اوس تھریڈ لئی، جُڑے repo چیک آؤٹ وچ اک Claude Code سیشن کھولدا اے۔ ہر تھریڈ سنیہا اجے وی `resume` نال اک Agent SDK `query()` چلاندا اے - سو `ensureBestAccount()` ہر ٹرن تے پول نوں مُڑ پرکھدا اے تے ڈیمن تھریڈ گوائے بغیر مُڑ چالو ہو سکدا اے (تھریڈ ریکارڈ پائیدار نیں؛ ڈیمن شروعات تے اوہناں نوں مُڑ سبسکرائب کر لیندا اے) - پر ہر کوئری سٹریمنگ ان پٹ لیندی اے، تے اِسے کر کے اک جواب پہلے توں چلدے ٹرن نوں سیدھ دے سکدا اے۔

غور طلب رویہ:

- **سیدھ دینا**: جیہڑا جواب اوس ویلے آوے جدوں تھریڈ دا ٹرن اجے چل رہیا ہووے، اوہ اوسے ٹرن وچ رل جاندا اے - بالکل اوہی مِڈ-ٹرن انجیکشن جیہڑا Claude Code تعاملی طور تے ورتدا اے - سو ماڈل نوں اوہ اپنی اگلی ٹول حد تے نظر آ جاندا اے تے اوہ غلط کم پہلاں مکان دی بجائے اپنا رخ درست کر لیندا اے۔ جیہڑا جواب ٹرن دی آخری ٹول کال توں بعد آوے اوہ فوراً اپنے آپ وچ اک الگ ٹرن بن کے چلدا اے؛ کسے وی صورت وچ کجھ وی نئیں چھُٹدا۔ سیدھ دِتے گئے سنیہے ریت گھڑی والی ری ایکشن پاندے نیں تے ٹرن نال ای مکدے نیں، تے اوہناں دی لکھت ٹرن دے پائیدار مارکر تے سوار ہو جاندی اے، سو مُڑ چالو ہون تے ورتوں دی حد توں بحالی ویلے وی اوہ مُڑ چلائی جاندی اے۔ صرف اوہ سنیہا جیہڑا کسے ہور اُڈیکدے سنیہے دے پِچھے قطار وچ ہووے، اوہ رَلن توں رہ جاندا اے (ترتیب برقرار رہندی اے)، تے خالی ہو رہیا ڈیمن سیدھ دین دی بجائے اجے وی اُچی آواز نال چھڈ دیندا اے۔
- **سٹریمنگ**: جواب مقامی طور تے Slack وچ سٹریم ہندے نیں، سوچ تے ٹول رنز لئی ٹاسک کارڈاں نال، واڑ والا کوڈ نمایانی نال رینڈر کیتا، لاگت تے مدت نال اک بند کرن والا "Turn" کارڈ؛ اک ٹرن دے سارے کارڈ اک کھُلن جوگے پلان بلاک وچ سمٹ جاندے نیں، سو اک ٹرن عام طور تے اک اکلے سنیہے وانگوں پڑھیا جاندا اے: جواب تے نال اوہدی سرگرمی دا اک ڈراپ ڈاؤن (ٹرن دے وچکار اک مُڑ کوشش یا اک رد کیتا ہویا append اک اگلا سنیہا کھولدا اے)۔ TodoWrite کالاں اک ٹِکی چیک لسٹ کارڈ نوں اوتھے ای اپڈیٹ کردیاں نیں۔
- **اجازتاں**: فی لنک `permissionMode` طے شدہ طور تے `acceptEdits` اے؛ `--yolo` (عرف `--dangerous`) اک لنک نوں `bypassPermissions` وچ پا دیندا اے۔ ریلے کیتے ٹرناں وچ تعاملی ڈائیلاگ منع نیں - کوئی وی اوہناں دا جواب Slack راہیں نئیں دے سکدا - سو ماڈل عبارت وچ پُچھدا اے تے تہاڈا تھریڈ جواب اگلا ٹرن ہندا اے۔ اک نال آیا پلگ اِن سکِل اوہنوں سِکھاندی اے کہ جدوں اوہنوں کوئی فیصلہ چاہیدا ہووے تاں بینتی کرن والے نوں ٹیگ کرے تے ٹرن مکا دیوے۔
- **حالت ری ایکشن**: جیس سنیہے نے اک ٹرن چالو کیتا اوہ اپنی حالت اک ایموجی ری ایکشن وانگوں چُکدا اے: ٹرن چلدیاں اک ریت گھڑی، فیر اک چیک نشان (مُک گیا)، اک x (ناکام)، یا اک سوالیہ نشان (ماڈل نوں تہاڈا فیصلہ چاہیدا اے)۔ ایہدے لئی موجودہ مینی فیسٹ توں `reactions:write` سکوپ چاہیدا اے؛ پہلاں توں بنیاں ایپاں نوں مینی فیسٹ مُڑ چیپنا تے مُڑ انسٹال کرنا پوندا اے۔
- **دھیان تے یاد کروائیاں**: جدوں ماڈل تہاڈے کولوں کوئی فیصلہ منگدا اے تاں اوہ اک اِن پروسیس `need_attention` ٹول سدّدا اے، تاں جو ڈیمن نوں پتہ ہووے کہ تھریڈ تہاڈی اُڈیک وچ اے۔ جے تُسیں 10 منٹ چُپ رہوو تاں اوہ تھریڈ وچ اک واری تہانوں ٹیگ کردا اے۔ جدوں تیک کوئی تھریڈ اُڈیک وچ ہووے، سوال تے ری ایکشن کرنا تہاڈے جواب وانگوں ریلے ہندا اے (اک thumbs up سفارش کیتی چون چُڑھا لیندا اے)؛ کسے ٹریک کیتے تھریڈ وچ تہاڈا کوئی وی ہور ری ایکشن اگلے ٹرن وچ سیاق وانگوں شامل کر لیا جاندا اے۔ ایہدے لئی `reactions:read` تے `reaction_added` ایونٹ چاہیدا اے۔
- **سلیش کمانڈاں**: اک تھریڈ سنیہا جیہدی چھِلی لکھت `/` نال شروع ہووے اوہ اک claude سلیش کمانڈ وانگوں چلدا اے۔ Slack دا کمپوزر `/` نال شروع ہون والے سنیہیاں نوں کھا جاندا اے، سو مینشن پہلاں والی صورت (`@bot /usage`) یا اگے اک خالی تھاں ورتو۔
- **ورتوں دی حد دی خودکار بحالی**: جدوں پول دا ہر اکاؤنٹ اپنی حد تے ہووے، تاں اک نِکی رکاوٹ سنیہے نوں پارک کر کے اوتھے ای مُڑ کوشش کردی اے؛ اک لمبی رکاوٹ اک اڈیک نوٹس چھاپدی اے تے پول دے بحال ہون تے ٹرن نوں خودکار طور تے بحال کر دیندی اے، ڈیمن دے مُڑ چالو ہون توں وی بچ کے۔ صرف اوہ حد جیہدا بحالی دا ویلا معلوم نہ ہووے تہاڈے کولوں سنیہا مُڑ گھلن لئی پُچھدی اے۔
- **سُچجی بندش**: SIGTERM/SIGINT خالی کردا اے - نویں ٹرن اُچی آواز نال چھڈے جاندے نیں، چلدے ٹرناں نوں 5 منٹ تیک مِلدے نیں، تے claude چائلڈ اپنے پروسیس گروپ وچ الگ ہو کے چلدا اے تاں جو اک ٹرمینل Ctrl-C ایہنوں خالی کرن ولوں ٹرن بچان توں پہلاں نہ مار سکے۔
- **تھریڈ صفائی**: جدوں تُسیں دسدے او کہ کم مُک گیا، ماڈل اک اِن پروسیس `finish_thread` ٹول سدّدا اے؛ ٹرن پوری طرحاں مُکن توں بعد، ڈیمن تھریڈ ریکارڈ چھڈ دیندا اے، اَن سبسکرائب کر دیندا اے، تے اک تصدیق چھاپدا اے۔ اک تازہ مینشن اک نواں سیشن شروع کردی اے۔
- **غلطی صفائی**: ٹرن غلطیاں چھانگی گئی صرف سنیہا لکھت چھاپدیاں نیں، کدے کچیاں غلطی باڈیاں نئیں۔
