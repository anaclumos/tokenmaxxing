---
title: स्थिति डायरेक्टरी लेआउट
description: "~/.config/tokenmaxxing के तहत हर फ़ाइल और डायरेक्टरी"
---

सब कुछ `~/.config/tokenmaxxing/` के तहत रहता है (`TOKENMAXXING_HOME` से ओवरराइड करने योग्य; हर बाहरी रूप से देखने योग्य पथ के लिए एक env ओवरराइड है ताकि पूरा टूल परीक्षणों में हर्मेटिक रूप से चल सके)।

| पथ | इसमें क्या होता है |
|---|---|
| `config.json` | आपकी कॉन्फ़िगरेशन (विरल; डिफ़ॉल्ट प्रति-फ़ील्ड लागू होते हैं) |
| `accounts.json` | पूल किए गए Claude खातों का गैर-गुप्त सूचकांक: लेबल, id, कैश की गई उपयोग विंडो। कभी टोकन नहीं |
| `usage.json` | statusline टी का समुच्चय विंडो स्नैपशॉट; इसका mtime फ़ीड का जीवंतता हार्टबीट है |
| `model-usage.json` | `/usage` से TTL-कैश की गई प्रति-मॉडल साप्ताहिक सीमाएं |
| `lastswap.json` | अंतिम स्वैप का epoch टाइमस्टैम्प; 45-सेकंड कूलडाउन को चलाता है |
| `lock` | `flock` फ़ाइल जो स्वैप को क्रमबद्ध करती है |
| `tokenmaxxing.log` | केवल-जोड़ने वाला इवेंट लॉग |
| `bin/` | PATH शिम: `claude`, `codex`, और `tokenmaxxing` / `xx` प्रवेश बिंदु |
| `respawn/<session-id>` | समाप्त-प्रतीक्षा respawn मार्कर जिन पर सुपरवाइज़र नज़र रखता है |
| `creds/` | केवल Linux: पार्क की गई क्रेडेंशियल फ़ाइलें, 0700 डायरेक्टरी में 0600 (macOS इसके बजाय क्रेडेंशियल को प्रति-खाता keychain आइटम के रूप में पार्क करता है) |
| `onboard/`, `sample/` | `add`/`auth` लॉगिन और पार्क-किए-गए-खाते के `/usage` प्रोब के लिए फेंकने योग्य पृथक config होम; प्लेनटेक्स्ट क्रेडेंशियल रखने वाले onboard होम हार्वेस्ट के बाद हटा दिए जाते हैं |
| `slack.json` | `xx serve` टोकन और चैनल लिंक (0600) |
| `slack-threads/` | `xx serve` के लिए प्रति-थ्रेड सेशन रिकॉर्ड |
| `codex-*` | समानांतर Codex पूल: `codex-accounts.json`, `codex-lastswap.json`, `codex-lock`, `codex-creds/`, `codex-onboard/`, `codex-respawn/`, और `codex-live/` (प्रति चालू पर्यवेक्षित codex सेशन एक PID-सत्यापित उपस्थिति फ़ाइल, ताकि एक लाइव खाता कभी स्वैप लक्ष्य न हो) |

अपनी स्वयं की डायरेक्टरी के बाहर, tokenmaxxing बिल्कुल इन्हें छूता है: `~/.claude.json` (`oauthAccount` स्वैप), Claude Code का `settings.json` (हुक और statusline प्रविष्टियां), लाइव क्रेडेंशियल स्टोर (macOS पर `Claude Code-credentials` keychain आइटम, Linux पर `.credentials.json`), `~/.claude.lock` (claude का रिफ्रेश लॉक, स्वैप के दौरान लिया गया), codex का `auth.json` और `hooks.json`, और launchd या systemd में आवधिक-जांच यूनिट।
