---
title: کمانڈاں
description: "ہر tokenmaxxing کمانڈ تے اوہ کیہ کردی اے"
---

| کمانڈ | ایہہ کیہ کردی اے |
|---|---|
| `tokenmaxxing init` | موجودہ اکاؤنٹ درآمد کرو، سُپروائزر، ہُک تے statusline انسٹال کرو |
| `tokenmaxxing init --codex` | Codex لئی اوہو: لاگ اِن درآمد کرو، codex سُپروائزر تے Stop ہُک انسٹال کرو |
| `tokenmaxxing add` | اک ہور اکاؤنٹ رجسٹر کرو (الگ تھلگ لاگ اِن، پول وچ سمیٹیا گیا) |
| `tokenmaxxing add --codex` | اک ہور Codex اکاؤنٹ رجسٹر کرو (الگ تھلگ لاگ اِن) |
| `tokenmaxxing auth [sel \| --all]` | پول دے اک اکاؤنٹ نوں اوتھے ای مُڑ تصدیق کرو۔ نِرا پول دی فہرست دیندا اے تے پُچھدا اے کیہڑا؛ اک سیلیکٹر اک اکاؤنٹ نوں نشانہ بناندا اے تے دسدا اے کیہڑی ای میل نال سائن اِن کرنا اے؛ `--all` ہر مُڑ تصدیق دی لوڑ والے اکاؤنٹ نوں اک اک کر کے وارو واری کردا اے |
| `tokenmaxxing switch [sel]` | بہترین اکاؤنٹ تے بدلو (لالچی، idempotent) یا کسے مخصوص اکاؤنٹ تے زبردستی بدلو |
| `tokenmaxxing switch --codex [sel]` | Codex پول بدلو (اگلی codex شروعات تے لاگو ہندا اے) |
| `tokenmaxxing ls` | پول دے اکاؤنٹاں دی فہرست |
| `tokenmaxxing status` | 5h / ہفتہ وار / فی ماڈل ورتوں بار نال اکاؤنٹ، چالو تے ری سیٹ تیک مُکے ہوئے |
| `tokenmaxxing status --force` | نال ای ہر اکاؤنٹ نوں پِنگ کرو (ہر اک نوں اک نِکی haiku بینتی) تاں جو سارے 5h سیشن ٹائمر ہُنے شروع ہو جان، فیر تازہ نمونہ لوو |
| `tokenmaxxing watch [seconds]` | لائیو سٹیٹس، ہر N سیکنڈ بعد مُڑ رینڈر کیتا گیا (طے شدہ 120، گھٹو گھٹ 30؛ کدے پِنگ نئیں کردا) |
| `tokenmaxxing config [get\|set\|unset\|tidy]` | ذرائع نال اثردار config؛ نقطے والیاں کیز سودھو؛ `tidy` انجان کیز چھانگ دیندا اے |
| `tokenmaxxing check` | بدلاؤ دا فیصلہ اک وار پرکھو (وقفے وار ٹائمر ایہو چلاندا اے) |
| `tokenmaxxing doctor` | پُشٹی کرو کہ سُپروائزر تے سیٹنگز اِندراج بچے ہوئے نیں |
| `tokenmaxxing rename [--codex] <sel> <label>` | پول دے اک اکاؤنٹ نوں مُڑ لیبل لاؤ |
| `tokenmaxxing rm [--codex] <sel>` | claude یا codex پول وچوں اک اکاؤنٹ (تے اوہدا پارکڈ کریڈینشل) ہٹاؤ |
| `tokenmaxxing uninstall` | سُپروائزر تے سیٹنگز اِندراج ہٹاؤ (اکاؤنٹ تے کریڈینشل رکھے جاندے نیں) |
