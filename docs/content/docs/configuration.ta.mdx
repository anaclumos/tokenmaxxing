---
title: கட்டமைப்பு (Configuration)
description: "config.json ஸ்கீமா, வரம்புகள், மற்றும் கொள்கை அமைப்புகள்"
---

கட்டமைப்பு `~/.config/tokenmaxxing/config.json` இல் JSON ஆக உள்ளது. ஒவ்வொரு புலமும் விருப்பமானது; இயல்புகள் ஒவ்வொரு புலத்திற்கும் பொருந்தும்.

```json
{
  "thresholds": { "session": [50, 80, 95], "weekly": 98 },
  "hardThresholds": { "session": 100, "weekly": 100 },
  "claudeBin": "/path/to/real/claude",
  "codexBin": "/path/to/real/codex",
  "policy": {
    "projectionMargin": 0,
    "greedySessionFloor": 50,
    "switchModels": ["fable"],
    "usagePollTtlMs": 90000,
    "maxWaitMs": 3600000
  }
}
```

- `thresholds.session`: 5-மணிநேர ஏணி, ஏறுவரிசையில் அமைந்த திரையிடல் படிகளின் பட்டியல். ஒவ்வொரு மதிப்பீடும் ஒரு செயல்படும் படியைத் தீர்மானிக்கிறது, அதாவது ஒன்றிணைந்த ஏதேனும் ஒரு கணக்கு இன்னும் தாண்டாத மிகக் கீழான படி; அந்தப் படியே தூண்டுதலும் வேட்பாளர் திரையும் ஆகும். Codex மேற்படியை மட்டுமே படிக்கிறது. [மாற்றம் எப்படி முடிவு செய்யப்படுகிறது](/ta/switching) ஐப் பார்க்கவும்.
- `thresholds.weekly`: வாராந்திர திரையிடல் பட்டை. இந்த ஒற்றைப் பட்டை 7-நாள் மொத்தத்தையும் ஒவ்வொரு-மாதிரி வாராந்திர வரம்பு அனைத்தையும் உள்ளடக்கியது.
- `hardThresholds.session` / `hardThresholds.weekly`: சுவர் பட்டைகள் (இயல்பு 100, ஒவ்வொரு கணக்கின் உண்மையான சேவையக வரம்பு). `hardThresholds.session` மேல் அமர்வுப் படிக்குச் சமமாகவோ அதற்கு மேலோ இருக்க வேண்டும். ஒவ்வொரு கணக்கும் அதன் திரையிடல் பட்டைக்கு மேல் இருக்கும்போது, நிறுத்துவதற்கு முன்பு தானியங்கி Claude முடிவு ஒவ்வொன்றையும் அதன் சுவர் வரை பிழிந்தெடுக்கிறது - [சுவர்](/ta/switching) ஐப் பார்க்கவும். முடக்க வேண்டுமானால் மேல் அமர்வுப் படிக்கும் வாராந்திரப் பட்டைக்கும் சமமாக அமைக்கவும்; Codex இந்த அமைப்பைப் புறக்கணிக்கிறது.
- `claudeBin` / `codexBin`: மேற்பார்வையாளர்கள் spawn செய்யும் உண்மையான பைனரிகளை பின் செய்கிறது (`init` / `init --codex` ஆல் எழுதப்படுகிறது; recursion-guard கண்டறிதல் செய்தி, `claudeBin` இனி உண்மையான Claude பைனரியை சுட்டிக்காட்டாதபோது இங்கே அதைச் சரிசெய்யச் சொல்கிறது).
- `policy.projectionMargin`: செயலில் உள்ள பட்டைகளை உருவாக்க ஒவ்வொரு அமர்வுப் படியிலிருந்தும், வாராந்திரப் பட்டையிலிருந்தும், சுவர் பட்டைகளிலிருந்தும் கழிக்கப்படுகிறது.
- `policy.greedySessionFloor`: பேராசை ஒன்றுசேர்தல் ஈடுபடும் அமர்வு-பயன்படுத்தப்பட்ட சதவீதம்.
- `policy.switchModels`: ஒரு மாற்றத்தை வாயிலிடும் ஒவ்வொரு-மாதிரி வாராந்திர வரம்பைக் கொண்ட மாதிரி குடும்பங்கள் (உள்ளீடுகள் ஏற்றப்படும்போது சிறிய எழுத்துக்களாக்கப்படுகின்றன).
- `policy.usagePollTtlMs`: ஒரு `/usage` ஒவ்வொரு-மாதிரி poll எவ்வளவு காலம் புத்துணர்ச்சியாக இருக்கிறது.
- `policy.maxWaitMs`: தீர்ந்துபோன-தொகுப்பு தானியங்கி-காத்திருப்பு வரம்பு.

`tokenmaxxing config` மூலங்களுடன் செயலில் உள்ள கட்டமைப்பைக் காட்டுகிறது; `config set`/`unset` புள்ளியிட்ட சாவிகளைத் திருத்துகிறது; `config tidy` தெரியாத சாவிகளை நீக்குகிறது.
