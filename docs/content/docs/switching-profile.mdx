The conservative 406 events contain 25,191 uncached input tokens, 82,059,975 cache-write tokens, and 6,455,496 cache-read tokens.

These are unmatched descriptive counts with repeated sessions and shared swap events, and neither the group rates nor their differences establish a causal effect.

Input weights use uncached input at 1, five-minute writes at 1.25, one-hour writes at 2, and standard reads at 0.1, following [API cache pricing](https://platform.claude.com/docs/en/build-with-claude/prompt-caching#pricing).

For flagged pairs with an observed swap, the arithmetic contrast is `(1-r) × uncached + (1.25-r) × five-minute writes + (2-r) × one-hour writes`, divided by all measured weighted input under the same read weight `r`.

This calculation includes new content and assumes every uncached or written token could instead be read, so it is neither a measured counterfactual nor an estimate of avoidable cost.

[Fable 5.1 pricing](https://www.anthropic.com/claude-fable-and-mythos-5-1) confirms the 0.025 ratio for that version, represented by 16,784 requests here, while applying it to all 41,139 Fable requests remains an assumption.

- Request time is the earliest assistant usage-row timestamp for the deduplicated request, a proxy for the unavailable actual request start.
- Identities join transitively through `message.id`, `requestId`, and `uuid`, retaining full relative path membership and counting copied requests once.
- The selected usage record has maximum reported output before the cutoff, with latest timestamp breaking ties, while groups with conflicting model or input counts are excluded.
- Canonical ownership prefers a path outside subagents, then the shallowest full path, then lexical order, retaining copied predecessors for context.
- Swaps qualify only when their completion timestamp falls strictly after the previous request timestamp and at or before the current one.
- The narrow stratum excludes gaps over 300 seconds and delayed adoption whose swap predates the previous request timestamp, so it does not capture every eventual account adoption.
- Organization inference joins logged short account IDs to unique current `accountUuid` and `organizationUuid` pairs, comparing consecutive frozen swap targets, with unknown results for missing or ambiguous matches or an unavailable predecessor.
- The first frozen swap has no predecessor in this snapshot and stays unknown, while a pair with multiple intervening swaps is unknown if any relation is unknown, otherwise cross if any is cross, otherwise same.
- Current membership may differ from historical membership, unlogged account changes may invalidate the predecessor assumption, and an observed global swap does not prove that a particular session adopted it.
- Prior write type suggests five-minute TTL for 175,349 conservative pairs and one-hour TTL for 15,186 pairs, with 69 unknown, but does not establish that the same prefix remains cached.
- [Current Claude Code defaults](https://code.claude.com/docs/en/prompt-caching#which-ttl-each-request-gets) give subscription main conversations one hour within plan usage and other requests five minutes except certain server-controlled helpers, while API and usage-credit requests default to five minutes.
- [Cache lifetime starts at request start and refreshes on reads](https://platform.claude.com/docs/en/build-with-claude/prompt-caching#how-prompt-caching-works), so response timing and missing prefix identity confound even the 300-second stratum.
- [Model changes, effort changes depending on model and version, and enabling fast mode](https://code.claude.com/docs/en/prompt-caching#actions-that-invalidate-the-cache) can invalidate caches, while prefix changes, compaction, concurrency, and expiry remain unmeasured explanations here.
- Output is excluded from every weighted denominator, and these normalized input units make no claim about subscription quota or savings.
- The earlier 8.7% figure used a different methodology and must not be cited as an estimate of switching cost, and this profile supplies no net estimate.
