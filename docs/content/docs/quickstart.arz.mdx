---
title: البداية السريعة
description: "ثبّت tokenmaxxing، استورد حسابك الحالي، وضمّ حسابات أكتر"
---

بيحتاج [Bun](https://bun.sh) و Claude Code، على macOS أو Linux. ثبّت بـ Bun، أو من الـ flake لو أصلاً بتستخدم Nix / nix-darwin. حط الـ CLI على PATH قبل `init` (بص [البناء والتوزيع](/arz/distribution)):

```sh
bun add -g tokenmaxxing
tokenmaxxing init
```

مستخدمين Nix بيستبدلوا خطوة Bun بـ `nix profile install github:anaclumos/tokenmaxxing`، أو بيفعّلوا `programs.tokenmaxxing` في إعدادات nix-darwin أو Home Manager بتاعتهم.

`init` بيعمل خمس حاجات:

1. بيستورد الحساب اللي انت أصلاً مسجّل دخول بيه كحساب رقم 1 (مفيش أمر `adopt` منفصل).
2. بيثبّت الـ `claude` supervisor shim.
3. بيثبّت أربع مدخلات في الـ `settings.json` بتاع Claude Code: statusLine، و Stop hook، و StopFailure hook، و SessionStart hook (بالإضافة لمدخل subagentStatusLine).
4. بيضيف مجلد الـ bin بتاع الـ supervisor لـ PATH في الـ shell rc بتاعك (idempotent، ومتعلّم عليه بتعليق `# tokenmaxxing PATH`). لازم يبقى قدّام الـ `claude` الحقيقي في الـ PATH عشان يعترضه.
5. بيثبّت timer للفحص الدوري (launchd agent على macOS، و systemd user timer على Linux) بيشغّل `tokenmaxxing check --if-due` مرة كل tick (`policy.checkIntervalMs`، 60 ثانية افتراضيًا)؛ والفحص بيظبط إيقاعه بنفسه بين tick وخمس ticks حسب المساحة الفاضية بتاعت الحساب الحي.

اعمل restart للـ shell بتاعك، وبعدين ضيف حسابات أكتر واتفضّل:

```sh
tokenmaxxing add        # بيسجّل دخول حساب زيادة، بمعزل، وبيضمّه للـ pool
claude                  # استخدم claude زي العادة
```

`tokenmaxxing` كمان ليه اسم مختصر `xx`. `tokenmaxxing` (أو `xx`) لوحده بيشغّل `status`؛ و `switch` بيفضل صريح.
