---
title: Konfigurasi
description: "Skema config.json, ambang batas, dan tombol kebijakan"
---

Konfigurasi berupa JSON di `~/.config/tokenmaxxing/config.json`. Setiap bidang opsional; default berlaku per-bidang.

```json
{
  "thresholds": { "session": 95, "weekly": 98 },
  "hardThresholds": { "session": 100, "weekly": 100 },
  "claudeBin": "/path/to/real/claude",
  "codexBin": "/path/to/real/codex",
  "policy": {
    "projectionMargin": 0,
    "greedySessionFloor": 50,
    "switchModels": ["fable"],
    "usagePollTtlMs": 90000,
    "maxWaitMs": 3600000
  }
}
```

- `thresholds.session` / `thresholds.weekly`: bilah penyaringan yang dijelaskan di [Cara pertukaran diputuskan](/id/switching).
- `hardThresholds.session` / `hardThresholds.weekly`: bilah dinding (default 100, batas server sebenarnya tiap akun). Ketika setiap akun melewati bilah penyaringannya, keputusan Claude otomatis memeras masing-masing hingga dindingnya sebelum memarkir - lihat [Dinding](/id/switching). Setel sama dengan `thresholds` untuk menonaktifkan; Codex mengabaikan pengaturan ini.
- `claudeBin` / `codexBin`: menetapkan biner ASLI yang dijalankan oleh para supervisor (ditulis oleh `init` / `init --codex`; diagnostik penjaga-rekursi memberitahumu untuk memperbaiki `claudeBin` di sini saat berhenti menunjuk ke biner Claude yang asli).
- `policy.projectionMargin`: dikurangkan dari bilah penyaringan maupun bilah dinding untuk membentuk bilah efektif.
- `policy.greedySessionFloor`: persen sesi-terpakai saat konvergensi rakus terlibat.
- `policy.switchModels`: keluarga model yang batas mingguan per-model-nya menggerbangi sebuah pertukaran (entri dijadikan huruf kecil saat dimuat).
- `policy.usagePollTtlMs`: berapa lama sebuah poll `/usage` per-model tetap segar.
- `policy.maxWaitMs`: batas penungguan-otomatis gabungan-habis.

`tokenmaxxing config` menampilkan konfigurasi efektif beserta sumbernya; `config set`/`unset` menyunting kunci bertitik; `config tidy` memangkas kunci yang tidak dikenal.
