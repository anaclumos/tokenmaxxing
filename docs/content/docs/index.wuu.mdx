## 问题所在

Claude 订阅会同时计量三种限额（用 `/usage` 侪确认得着）：

- **当前礼拜（所有模型）**：7 天嗰汇总。
- **当前礼拜，分模型**：单个模型系列各自嗰礼拜上限。搿眼现在只有 Sonnet 搭 Fable 有，而且只有 Fable 嗰上限紧得来才要紧，伊比汇总早老早就顶牢类。一台机器好一面礼拜总量才 50%，一面礼拜 Fable 已经到 80% 类。
