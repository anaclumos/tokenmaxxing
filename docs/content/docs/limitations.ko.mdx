title: 솔직한 제약
description: "풀 기반 hot-swap에 따르는 트레이드오프"
---

- **한 번의 콜드 턴.** 프롬프트 캐시는 조직 범위이므로 새 계정의 첫 턴은 컨텍스트를 한 번 다시 업로드합니다.
- **소진 일시 정지의 작은 문제.** 완전히 소진된 풀만이 카운트다운 동안 세션을 멈춥니다. 그 찰나에 입력한 것은 모두 사라집니다.
- **채택 지연.** macOS에서는 교체 후 약 30초 안에 실행되는 첫 턴이 여전히 이전 계정에 집계될 수 있습니다. 기준선의 여유분이 이를 흡수합니다.
- **공유되는 영향 범위.** 모든 기본 프로필 세션이 하나의 라이브 자격 증명을 공유하므로 한 번 교체하면 모두 함께 넘어갑니다(각자 그 자리에서 채택합니다).
- **Linux의 평문 자격 증명.** Claude Code 자체가 Linux 자격 증명을 0600 평문 파일로 저장합니다. tokenmaxxing의 보관 사본도 같은 방식을 따릅니다.
