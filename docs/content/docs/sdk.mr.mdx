---
title: Agent SDK पृष्ठभाग
description: "तुम्ही स्वतः चालवत असलेल्या एजंट्समध्ये पूलला Claude Agent SDK शी जोडा"
---

पॅकेजचा प्रोग्रामॅटिक एंट्री (`exports["."]` `src/sdk.ts` कडे इशारा करतो) tokenmaxxing ला Claude Agent SDK शी जोडतो, तुम्ही तुमच्या स्वतःच्या पूल केलेल्या खात्यांविरुद्ध बांधलेल्या एजंट्ससाठी. तुमचा अॅप Bun अंतर्गत चालला पाहिजे (tokenmaxxing TypeScript स्रोत पाठवते आणि `bun:ffi` वापरते).

```ts
import { query } from "@anthropic-ai/claude-agent-sdk";
import { ensureBestAccount, pooledOptions, stopHookCheck } from "tokenmaxxing";

await ensureBestAccount();

for await (const message of query({
  prompt: "...",
  options: {
    ...pooledOptions(),
    hooks: { Stop: [{ hooks: [stopHookCheck] }] },
  },
})) {
}
```

लूप बॉडीला संदेशांचा प्रवाह मिळतो; बदलांदरम्यान `resume` हवे असल्यास init संदेशातील session id जपून ठेवा.

Agent SDK प्रति `query()` एक claude सबप्रोसेस स्पॉन करते आणि स्पॉनवर एकदाच क्रेडेन्शियल्स वाचते - कोणतीही statusline नाही, कोणताही मध्य-क्वेरी हॉट-स्वॅप नाही - त्यामुळे एकत्रीकरण सीमा-आधारित आहे:

- `ensureBestAccount()` हा नेमका तोच निर्णय आहे जो CLI हुक्स आणि टायमर चालवतात (बार, गती दबाव, कूलडाउन, सर्व सामायिक कोड), कधीही पूर्वानुमानात्मक नाही: एक SDK सत्र संपलेल्या काउंटडाउनसाठी कधीही थांबवले जाऊ शकत नाही.
- `pooledOptions()` `pathToClaudeCodeExecutable` ला खऱ्या claude बायनरीशी पिन करते (कधीही पर्यवेक्षक रॅपर नाही) आणि प्रत्येक सभोवतालचे क्रेडेन्शियल ओव्हरराइड स्वच्छ केलेले संपूर्ण बदली `env` पुरवते. जर तुमच्या अॅपच्या वातावरणात `CLAUDE_CONFIG_DIR` किंवा `CLAUDE_SECURESTORAGE_CONFIG_DIR` सेट असेल तर ते झटपट अपयशी होते: Linux वर एक बदल थेट क्रेडेन्शियल त्या जिथे इशारा करतात तिथे लिहेल तर स्वच्छ केलेला सबप्रोसेस डीफॉल्ट स्टोअर वाचतो, एक गप्प चुकीच्या-खात्याचा डीसिंक.
- `stopHookCheck` टर्न सीमांवर निर्णय पुन्हा-चालवते; तो जो बदल उतरवतो तो पुढील स्पॉनवर लागू होतो. तो पुन्हा फेकण्याऐवजी त्याच्या स्वतःच्या त्रुटी पकडतो (stderr आणि लॉगमध्ये लॉग करत), कारण न-हाताळलेला हुक अपवाद एजंटमध्ये व्यत्यय आणू शकतो, आणि तुटलेल्या बदल तपासणीवरून टर्न रद्द करणे सध्याचे खाते पार करण्यापेक्षा जास्त महाग पडते.

`sdk.ts` Agent SDK कडून स्वतः काहीही आयात करत नाही; त्याची मूल्ये संरचनात्मकपणे SDK च्या पर्यायांमध्ये पसरतात.
