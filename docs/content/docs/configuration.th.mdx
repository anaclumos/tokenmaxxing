---
title: การตั้งค่า
description: "สคีมาของ config.json ค่าเกณฑ์ และปุ่มปรับนโยบาย"
---

การตั้งค่าเป็น JSON อยู่ที่ `~/.config/tokenmaxxing/config.json` ทุกฟิลด์เป็นทางเลือก และค่าเริ่มต้นจะถูกใช้เป็นรายฟิลด์

```json
{
  "thresholds": { "session": [50, 80, 95], "weekly": 98 },
  "hardThresholds": { "session": 100, "weekly": 100 },
  "claudeBin": "/path/to/real/claude",
  "codexBin": "/path/to/real/codex",
  "policy": {
    "projectionMargin": 0,
    "greedySessionFloor": 50,
    "switchModels": ["fable"],
    "usagePollTtlMs": 90000,
    "maxWaitMs": 3600000
  }
}
```

- `thresholds.session`: บันไดของหน้าต่าง 5 ชั่วโมง เป็นรายการขั้นคัดกรองที่เรียงจากน้อยไปมาก การประเมินแต่ละครั้งจะหาขั้นที่มีผลอยู่หนึ่งขั้น คือขั้นต่ำสุดที่ยังมีบัญชีในพูลบางบัญชีผ่านอยู่ และขั้นนั้นเป็นทั้งตัวกระตุ้นและตัวคัดกรองบัญชีที่จะเป็นตัวเลือก Codex อ่านเฉพาะขั้นบนสุดเท่านั้น ดู [การตัดสินใจสลับบัญชีทำงานอย่างไร](/th/switching)
- `thresholds.weekly`: แถบคัดกรองรายสัปดาห์ ครอบคลุมทั้งยอดรวม 7 วันและลิมิตรายสัปดาห์แยกตามโมเดลทุกตัว
- `hardThresholds.session` / `hardThresholds.weekly`: แถบกำแพง (ค่าเริ่มต้น 100 คือลิมิตจริงบนเซิร์ฟเวอร์ของแต่ละบัญชี) `hardThresholds.session` ต้องมีค่าไม่ต่ำกว่าขั้นบนสุดของ session เมื่อทุกบัญชีเกินแถบคัดกรองของตัวเองแล้ว การตัดสินใจอัตโนมัติของ Claude จะรีดใช้แต่ละบัญชีจนถึงกำแพงก่อนที่จะพัก - ดู [กำแพง](/th/switching) ตั้งให้เท่ากับขั้นบนสุดและแถบรายสัปดาห์เพื่อปิดใช้งาน Codex จะไม่สนใจการตั้งค่านี้
- `claudeBin` / `codexBin`: ตรึงไว้กับไบนารีจริงที่ supervisor เป็นผู้สั่งรัน (เขียนโดย `init` / `init --codex`; ข้อความวินิจฉัยของตัวป้องกันการเรียกซ้ำจะบอกให้คุณมาแก้ `claudeBin` ตรงนี้เมื่อมันไม่ชี้ไปยังไบนารี Claude จริงอีกต่อไป)
- `policy.projectionMargin`: ค่าที่ถูกลบออกจากขั้น session ทุกขั้น จากแถบรายสัปดาห์ และจากแถบกำแพง เพื่อสร้างแถบที่มีผลจริง
- `policy.greedySessionFloor`: เปอร์เซ็นต์การใช้เซสชันที่การลู่เข้าแบบ greedy จะเริ่มทำงาน
- `policy.switchModels`: ตระกูลโมเดลที่ลิมิตรายสัปดาห์แยกตามโมเดลจะเปิดประตูให้สลับ (รายการจะถูกแปลงเป็นตัวพิมพ์เล็กเมื่อโหลด)
- `policy.usagePollTtlMs`: การ poll `/usage` แยกตามโมเดลจะคงความสดใหม่นานเท่าใด
- `policy.maxWaitMs`: ขอบเขตการรออัตโนมัติเมื่อพูลหมด

`tokenmaxxing config` แสดงการตั้งค่าที่มีผลจริงพร้อมแหล่งที่มา `config set`/`unset` แก้ไขคีย์แบบจุด `config tidy` ตัดคีย์ที่ไม่รู้จักออก
