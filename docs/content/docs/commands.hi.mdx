---
title: कमांड
description: "हर tokenmaxxing कमांड और वह क्या करता है"
---

| कमांड | यह क्या करता है |
|---|---|
| `tokenmaxxing init` | वर्तमान खाता आयात करें, सुपरवाइज़र, हुक, और statusline इंस्टॉल करें |
| `tokenmaxxing init --codex` | Codex के लिए वही: लॉगिन आयात करें, codex सुपरवाइज़र और Stop हुक इंस्टॉल करें |
| `tokenmaxxing add` | एक अतिरिक्त खाता पंजीकृत करें (पृथक लॉगिन, पूल में हार्वेस्ट किया गया) |
| `tokenmaxxing add --codex` | एक अतिरिक्त Codex खाता पंजीकृत करें (पृथक लॉगिन) |
| `tokenmaxxing auth [sel \| --all]` | किसी पूल किए गए खाते को उसकी जगह पर पुनः प्रमाणित करें। सादा पूल की सूची देता है और पूछता है कि कौन सा; एक चयनकर्ता एक खाते को लक्षित करता है और आपको बताता है कि किस ईमेल से साइन इन करना है; `--all` हर एक needs-reauth खाते को एक-एक करके देखता है |
| `tokenmaxxing switch [sel]` | सर्वश्रेष्ठ खाते पर स्विच करें (लोभी, idempotent) या किसी विशिष्ट खाते को बाध्य करें |
| `tokenmaxxing switch --codex [sel]` | Codex पूल को स्विच करें (अगले codex आरंभ पर प्रभावी होता है) |
| `tokenmaxxing ls` | पूल किए गए खातों की सूची दें |
| `tokenmaxxing status` | 5h / साप्ताहिक / प्रति-मॉडल उपयोग बार वाले खाते, सक्रिय और रीसेट-तक-समाप्त |
| `tokenmaxxing status --force` | अतिरिक्त रूप से हर खाते को पिंग करें (प्रत्येक को एक छोटा सा haiku अनुरोध) ताकि सभी 5h सेशन टाइमर अभी शुरू हो जाएं, फिर नए सिरे से नमूना लें |
| `tokenmaxxing watch [seconds]` | लाइव स्थिति, हर N सेकंड में फिर से रेंडर की गई (डिफ़ॉल्ट 120, न्यूनतम 30; कभी पिंग नहीं करती) |
| `tokenmaxxing config [get\|set\|unset\|tidy]` | स्रोतों के साथ प्रभावी config; डॉटेड कुंजियां संपादित करें; `tidy` अज्ञात कुंजियों को छांटता है |
| `tokenmaxxing check` | स्विच निर्णय का एक बार मूल्यांकन करें (यही आवधिक टाइमर चलाता है) |
| `tokenmaxxing serve [setup\|link\|unlink\|links]` | Slack ब्रिज डेमन (Socket Mode, कोई सार्वजनिक URL नहीं) |
| `tokenmaxxing doctor` | सत्यापित करें कि सुपरवाइज़र और सेटिंग्स प्रविष्टियां बची रहीं |
| `tokenmaxxing rename [--codex] <sel> <label>` | किसी पूल किए गए खाते को फिर से लेबल करें |
| `tokenmaxxing rm <sel>` | पूल से एक खाता हटाएं |
| `tokenmaxxing uninstall` | सुपरवाइज़र और सेटिंग्स प्रविष्टियां हटाएं (खाते और क्रेडेंशियल रखे जाते हैं) |
