title: 개인적 사용과 이용약관
description: "직접 보유한 계정을, 직접 실행하는 세션과 에이전트에서 모아 쓰세요"
---

tokenmaxxing은 직접 보유한 계정을, 직접 실행하는 세션과 에이전트에서 모아 씁니다. 그 표현은 의도적입니다. Anthropic은 제3자 제품이 claude.ai 로그인이나 claude.ai 사용 한도를 제공하는 것을 허용하지 않으며 여기에는 Agent SDK로 만든 에이전트도 포함됩니다. 풀 SDK 표면이나 이를 기반으로 만든 어떤 것도 제3자에게 배포하지 마세요. 또한 tokenmaxxing은 할당량 데이터를 얻을 때 OAuth를 다시 구현하거나 API 트래픽을 프록시하는 대신 CLI를 거치는 `/usage` 경로에 의도적으로 머무릅니다. 이는 프록시가 아닙니다. 건드리는 유일한 OAuth 엔드포인트는 교체 중에 쓰는 표준 갱신 grant와 토큰이 실제로 어느 계정에 속하는지 확인하는 읽기 전용 신원 확인(roles 엔드포인트)뿐입니다.
