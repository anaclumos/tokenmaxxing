---
title: Inicio rápido
description: "Instala tokenmaxxing, importa tu cuenta actual y agrupa más"
---

Requiere [Bun](https://bun.sh) y Claude Code, en macOS o Linux. Instala con Bun, o desde el flake si ya usas Nix / nix-darwin. Pon la CLI en el PATH antes de `init` (consulta [Compilación y distribución](/es/distribution)):

```sh
bun add -g tokenmaxxing
tokenmaxxing init
```

Quienes usan Nix sustituyen el paso de Bun por `nix profile install github:anaclumos/tokenmaxxing`, o habilitan `programs.tokenmaxxing` en su configuración de nix-darwin o Home Manager.

`init` hace cinco cosas:

1. Importa la cuenta con la que ya has iniciado sesión como cuenta #1 (no hay un comando `adopt` aparte).
2. Instala el shim supervisor de `claude`.
3. Instala cuatro entradas en el `settings.json` de Claude Code: un statusLine, un hook Stop, un hook StopFailure y un hook SessionStart (más una entrada subagentStatusLine).
4. Añade el directorio bin del supervisor al PATH del rc de tu shell (idempotente, marcado con un comentario `# tokenmaxxing PATH`). Tiene que ir por delante del `claude` real en el PATH para interceptarlo.
5. Instala un temporizador de comprobación periódica (un agente launchd en macOS, un temporizador de usuario systemd en Linux) que ejecuta `tokenmaxxing check --if-due` cada 60 segundos; la comprobación marca su propio ritmo entre uno y cinco minutos según el margen de la cuenta en vivo.

Reinicia tu shell, luego añade más cuentas y adelante:

```sh
tokenmaxxing add        # inicia sesión con una cuenta más, en aislamiento, y la agrupa
claude                  # usa claude como siempre
```

`tokenmaxxing` también tiene el alias `xx`. `tokenmaxxing` (o `xx`) a secas ejecuta `status`; `switch` se mantiene explícito.
