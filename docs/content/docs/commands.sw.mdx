---
title: Amri
description: "Kila amri ya tokenmaxxing na inachofanya"
---

| Amri | Inafanya nini |
|---|---|
| `tokenmaxxing init` | Ingiza akaunti ya sasa, sakinisha msimamizi, hooks, na statusline |
| `tokenmaxxing init --codex` | Vivyo hivyo kwa Codex: ingiza uingiaji, sakinisha msimamizi wa codex na Stop hook |
| `tokenmaxxing add` | Sajili akaunti ya ziada (uingiaji uliojitenga, ulioingizwa kwenye mkusanyiko) |
| `tokenmaxxing add --codex` | Sajili akaunti ya ziada ya Codex (uingiaji uliojitenga) |
| `tokenmaxxing auth [sel \| --all]` | Thibitisha upya akaunti iliyokusanywa papo hapo. Peke yake huorodhesha mkusanyiko na kuuliza ipi; kiteuzi kinalenga akaunti moja na kinakuambia barua pepe ipi ya kuingia nayo; `--all` hupitia kila akaunti inayohitaji uthibitishaji-upya moja baada ya nyingine |
| `tokenmaxxing switch [sel]` | Badilisha hadi akaunti bora zaidi (greedy, idempotent) au lazimisha maalum |
| `tokenmaxxing switch --codex [sel]` | Badilisha mkusanyiko wa Codex (huanza kufanya kazi kwenye kuanzisha codex kunakofuata) |
| `tokenmaxxing ls` | Orodhesha akaunti zilizokusanywa |
| `tokenmaxxing status` | Akaunti zenye baa za matumizi za saa 5 / kila wiki / kila muundo, zinazotumika na zilizokwisha-hadi-kujiweka-upya |
| `tokenmaxxing status --force` | Zaidi ya hayo tuma ping kwa kila akaunti (ombi moja dogo la haiku kila moja) ili vipima muda vyote vya kikao cha saa 5 vianze sasa, kisha chukua sampuli mpya |
| `tokenmaxxing watch [seconds]` | Hali ya moja kwa moja, inayoonyeshwa upya kila sekunde N (chaguo-msingi 120, sakafu 30; haitumi ping kamwe) |
| `tokenmaxxing config [get\|set\|unset\|tidy]` | Usanidi unaotumika pamoja na vyanzo; hariri funguo zenye nukta; `tidy` hupogoa funguo zisizojulikana |
| `tokenmaxxing check` | Tathmini uamuzi wa kubadilisha mara moja (hiki ndicho kipima muda cha mara kwa mara huendesha) |
| `tokenmaxxing serve [setup\|link\|unlink\|links]` | Daemon ya daraja la Slack (Socket Mode, hakuna URL ya umma) |
| `tokenmaxxing doctor` | Thibitisha msimamizi na viingizo vya mipangilio vimesalia |
| `tokenmaxxing rename [--codex] <sel> <label>` | Weka lebo upya akaunti iliyokusanywa |
| `tokenmaxxing rm [--codex] <sel>` | Ondoa akaunti (na kitambulisho chake kilichohifadhiwa) kwenye mkusanyiko wa claude au codex |
| `tokenmaxxing uninstall` | Ondoa msimamizi na viingizo vya mipangilio (akaunti na vitambulisho vinahifadhiwa) |
