---
title: ข้อจำกัดที่บอกตามตรง
description: "ข้อแลกเปลี่ยนที่มาพร้อมกับการ hot-swap แบบรวมพูล"
---

- **เทิร์นเย็นหนึ่งครั้ง** แคชพรอมต์อยู่ในขอบเขตขององค์กร ดังนั้นเทิร์นแรกบนบัญชีใหม่จะอัปโหลดบริบทซ้ำหนึ่งครั้ง
- **สะดุดเมื่อหยุดชั่วคราวตอนหมดโควตา** เฉพาะพูลที่หมดเกลี้ยงทั้งพูลเท่านั้นที่จะหยุดเซสชันเพื่อนับถอยหลัง สิ่งใดที่พิมพ์ในเสี้ยววินาทีนั้นจะสูญหาย
- **ความหน่วงในการนำมาใช้** บน macOS เทิร์นแรกภายในประมาณ 30 วินาทีของการสลับยังอาจนับการใช้กับบัญชีเก่าได้ พื้นที่เหลือของแถบจะรองรับมันไว้
- **รัศมีผลกระทบที่ใช้ร่วมกัน** ทุกเซสชันในโปรไฟล์เริ่มต้นใช้ credential สดตัวเดียวกัน ดังนั้นการสลับจะย้ายทั้งหมดไปพร้อมกัน (แต่ละเซสชันนำมาใช้ ณ ที่เดิม)
- **credential แบบข้อความธรรมดาบน Linux** Claude Code เองเก็บ credential บน Linux เป็นไฟล์ข้อความธรรมดาสิทธิ์ 0600 สำเนาที่ park ไว้ของ tokenmaxxing ก็ใช้โมเดลเดียวกัน
- **หนึ่งพูลต่อหนึ่งเครื่อง** การรวมพูลบัญชีเดียวกันบนหลายเครื่องทำได้ แต่แต่ละเครื่องจะ park และหมุนเวียน token อย่างเป็นอิสระจากกัน โดยไม่มีล็อกข้ามเครื่อง: การรีเฟรช token ของบัญชีเดียวกันจากสองเครื่องพร้อมกันจะแข่งกัน และสำหรับ Codex การรีเฟรชจากสำเนาที่ park ไว้ซึ่งล้าสมัยจะทำให้ล็อกอินนั้นใช้การไม่ได้ทันที (OpenAI จะทำให้ grant family ทั้งหมดใช้ไม่ได้เมื่อมีการใช้ refresh token ซ้ำ บังคับให้ต้อง `auth` ใหม่บนทุกเครื่อง) หากคุณรวมพูลบัญชีเดียวกันไว้มากกว่าหนึ่งเครื่อง ให้คาดว่าจะมีการต้อง reauth เป็นครั้งคราวบน Claude และหลีกเลี่ยงการทำเช่นนั้นโดยสิ้นเชิงสำหรับ Codex
