---
title: కమాండ్‌లు
description: "ప్రతి tokenmaxxing కమాండ్ మరియు అది ఏమి చేస్తుంది"
---

| కమాండ్ | ఇది ఏమి చేస్తుంది |
|---|---|
| `tokenmaxxing init` | ప్రస్తుత ఖాతాను దిగుమతి చేయండి, సూపర్‌వైజర్, హుక్‌లు, మరియు statuslineను ఇన్‌స్టాల్ చేయండి |
| `tokenmaxxing init --codex` | Codex కోసం అదే: లాగిన్‌ను దిగుమతి చేయండి, codex సూపర్‌వైజర్ మరియు Stop హుక్‌ను ఇన్‌స్టాల్ చేయండి |
| `tokenmaxxing add` | అదనపు ఖాతాను నమోదు చేయండి (వేరుచేసిన లాగిన్, పూల్‌లోకి సేకరించబడుతుంది) |
| `tokenmaxxing add --codex` | అదనపు Codex ఖాతాను నమోదు చేయండి (వేరుచేసిన లాగిన్) |
| `tokenmaxxing auth [sel \| --all]` | పూల్ చేసిన ఖాతాను యథాస్థానంలో తిరిగి ప్రామాణీకరించండి. ఒట్టిది పూల్‌ను జాబితా చేసి ఏది అని అడుగుతుంది; ఒక సెలెక్టర్ ఒక ఖాతాను లక్ష్యంగా చేసుకుని ఏ ఇమెయిల్‌తో సైన్ ఇన్ చేయాలో చెబుతుంది; `--all` తిరిగి-ప్రామాణీకరణ అవసరమైన ప్రతి ఖాతాను ఒక్కొక్కటిగా నడుస్తుంది |
| `tokenmaxxing switch [sel]` | ఉత్తమ ఖాతాకు మారండి (అత్యాశ, ఇడెంపొటెంట్) లేదా నిర్దిష్ట ఖాతాను బలవంతం చేయండి |
| `tokenmaxxing switch --codex [sel]` | Codex పూల్‌ను మార్చండి (తదుపరి codex ప్రారంభంలో అమలులోకి వస్తుంది) |
| `tokenmaxxing ls` | పూల్ చేసిన ఖాతాలను జాబితా చేయండి |
| `tokenmaxxing status` | 5గం / వారపు / ప్రతి-మోడల్ వినియోగ బార్‌లతో ఖాతాలు, క్రియాశీలం మరియు రీసెట్-వరకు-ఖాళీ |
| `tokenmaxxing status --force` | అదనంగా ప్రతి ఖాతాను పింగ్ చేయండి (ఒక్కొక్కదానికి ఒక చిన్న haiku అభ్యర్థన) తద్వారా అన్ని 5గం సెషన్ టైమర్‌లు ఇప్పుడు ప్రారంభమవుతాయి, తర్వాత తాజాగా నమూనా చేయండి |
| `tokenmaxxing watch [seconds]` | ప్రత్యక్ష స్థితి, ప్రతి N సెకన్లకు తిరిగి రెండర్ చేయబడుతుంది (డిఫాల్ట్ 120, కనిష్ఠం 30; ఎప్పుడూ పింగ్ చేయదు) |
| `tokenmaxxing config [get\|set\|unset\|tidy]` | మూలాలతో అమలులో ఉన్న కాన్ఫిగ్; డాట్ చేసిన కీలను సవరించండి; `tidy` తెలియని కీలను తొలగిస్తుంది |
| `tokenmaxxing check` | మార్పిడి నిర్ణయాన్ని ఒకసారి మూల్యాంకనం చేయండి (ఆవర్తన టైమర్ నడిపేది ఇదే) |
| `tokenmaxxing doctor` | సూపర్‌వైజర్ మరియు సెట్టింగ్‌ల ఎంట్రీలు నిలిచి ఉన్నాయని ధృవీకరించండి |
| `tokenmaxxing rename [--codex] <sel> <label>` | పూల్ చేసిన ఖాతాకు తిరిగి లేబుల్ ఇవ్వండి |
| `tokenmaxxing rm [--codex] <sel>` | క్లాడ్ లేదా కోడెక్స్ పూల్ నుండి ఒక ఖాతాను (మరియు దాని పార్క్ చేసిన క్రెడెన్షియల్‌ను) తొలగించండి |
| `tokenmaxxing uninstall` | సూపర్‌వైజర్ మరియు సెట్టింగ్‌ల ఎంట్రీలను తొలగించండి (ఖాతాలు మరియు క్రెడెన్షియల్‌లు ఉంచబడతాయి) |
