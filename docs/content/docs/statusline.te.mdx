tokenmaxxing Claude Code యొక్క statuslineను స్థానికంగా రెండర్ చేస్తుంది (వినియోగ ఫీడ్‌ను టీ చేస్తూనే). రూపకల్పన సూత్రం: కోటా సంఖ్యలలో కాదు, రంగులో మోయబడుతుంది. ఉదాహరణకు, ఒక లైన్:

```
tm-wt-demo Fable 5 (high) +156/-23  ◆ 𝒇 2h 1d  ◇ 19h  ◇ 𝒇 2d  ◇ full  ✗ ?
```

- ప్రతి విండో టోకెన్ దాని రీసెట్-వరకు-సమయం, వాడిన శాతం ద్వారా నిరంతర ఆకుపచ్చ-నుండి-పసుపు-నుండి-ఎరుపు ర్యాంప్‌పై చిత్రించబడుతుంది (టెర్మినల్ మద్దతిస్తే ట్రూకలర్, లేకపోతే 256-రంగుల క్యూబ్‌పైకి మెట్లుగా). ర్యాంప్ 0కి స్వచ్ఛమైన ఆకుపచ్చ వద్ద, 75 వద్ద పసుపు, మరియు 95 మరియు అంతకంటే ఎక్కువ వద్ద ఎరుపు వద్ద ఆంకర్ అవుతుంది, కాబట్టి పాత తీవ్రత బ్యాండ్‌లు ర్యాంప్ ఆంకర్‌లుగా నిలుస్తాయి.
- మోడల్ పేరు అదే ర్యాంప్‌పై కాంటెక్స్ట్-విండో ఫిల్ ద్వారా చిత్రించబడుతుంది.
- ఆకుపచ్చ `◆` క్రియాశీల ఖాతా విండోలకు ముందుంటుంది; ప్రతి పార్క్ చేసిన ఖాతాకు దాని స్వంత సియాన్ `◇` వస్తుంది (తిరిగి-ప్రామాణీకరణ అవసరమైతే ఎరుపు `✗`). ఖాతాలు త్వరగా రాబోయే రీసెట్ ప్రకారం క్రమబద్ధీకరించబడతాయి.
- ప్రతి బ్లాక్‌లో ప్రతి-మోడల్ ఒక ఒట్టి చిత్రించిన మొదటి అక్షరంగా ముందుగా వస్తుంది: Fable `𝒇`గా రెండర్ అవుతుంది; ఇతర కుటుంబాలు తమ పెద్ద-అక్షర మొదటి అక్షరాన్ని ఉపయోగిస్తాయి, ఎల్లప్పుడూ కుటుంబ-సరిపోల్చబడతాయి.
- తాకని పార్క్ చేసిన ఖాతా ఆకుపచ్చ `full`గా రెండర్ అవుతుంది. తెలియని రీసెట్‌తో కొలిచిన వినియోగం ఒక చిత్రించిన `?`గా రెండర్ అవుతుంది, మరియు గేట్ చేసిన మోడల్‌పై కొలవని ప్రతి-మోడల్ పరిమితి ఒక చిత్రించని `𝒇?`గా రెండర్ అవుతుంది - కొలవనిది ఎప్పుడూ సురక్షితంగా కనిపించకూడదు.
- రీసెట్ కౌంట్‌డౌన్‌లు అతిపెద్ద యూనిట్‌ను మాత్రమే చూపుతాయి, ఎప్పుడూ "now" లేదా "0m" కాదు; రాబోయే రీసెట్ లేని విండో ఆకుపచ్చ `0`గా రెండర్ అవుతుంది (మళ్ళీ ఖాళీ).
- లింక్ చేసిన git worktree యొక్క బేస్‌నేమ్ లైన్‌కు ముందుంటుంది; ప్రధాన చెక్‌అవుట్ అక్కడ ఏదీ రెండర్ చేయదు. గుర్తింపు `.git` ఫైల్ కోసం ఫైల్‌సిస్టమ్‌ను చదువుతుంది మరియు ఏ git సబ్‌ప్రాసెస్‌ను ఎప్పుడూ స్పాన్ చేయదు.
- `NO_COLOR` సెట్ చేసినప్పుడు, లైన్ ఒక అతికించిన సంఖ్యా ఫార్మాట్‌కు తిరిగివస్తుంది (`2h5` అంటే 2 గంటల్లో రీసెట్ అవుతుంది, 5% వాడబడింది; కాంటెక్స్ట్ ఫిల్ కోసం `ctx 42`) - రంగు లేకుండా, ఖాళీ అయిన విండో తాజాగా కనిపించకూడదు.

సబ్‌ఏజెంట్ టాస్క్‌లు claude యొక్క subagentStatusLine ఉపరితలం ద్వారా తమ స్వంత ప్యానెల్ వరుసలను పొందుతాయి: ప్రతి క్రియాశీల టాస్క్‌కు ఒక వరుస, ఆ టాస్క్ యొక్క కాంటెక్స్ట్ ఫిల్ ద్వారా చిత్రించిన కుటుంబ పేరు.
