description: "npm 上发布 TypeScript 源码，由 Bun 运行，发布时带有来源证明"

npm 包发布的是 TypeScript 源码，而非构建产物：`tokenmaxxing` bin 直接指向带 Bun shebang 的 `src/main.ts`，Bun 1.2.6 或更新版本会原样运行。Bun 因此成为硬性要求。刻意不提供任何编译好的二进制：早期曾有一个版本向每个平台都发布了单个 61 MB 的 macOS 二进制，在 Linux 上以 `exec format error` 失败，而按平台编译的包又各自需要一套发布流水线，因此由 Bun 运行源码成了分发模式。

该包的 `exports` 映射把 `src/sdk.ts` 暴露为 [Agent SDK 接口](/sdk) 中所述的编程入口。发布版本在 GitHub 上以 `v<version>` 打标签；CI 通过可信发布（OIDC，带有来源证明）发布到 npm，且发布关卡会先运行类型检查和完整的测试套件。
