title: البناء والتوزيع
description: "كود TypeScript على npm، بيشتغل بـ Bun، وبيتنشر مع provenance"
---

باكدج الـ npm بيشحن كود TypeScript، مش build: الـ `tokenmaxxing` bin بيأشّر على طول على `src/main.ts` بـ Bun shebang، و Bun 1.2.6 أو أحدث بيشغّله زي ما هو. عشان كده Bun مطلب أساسي. مفيش binaries مترجمة عن قصد في التصميم: إصدار بدري شحن binary واحد بحجم 61 MB لـ macOS لكل المنصات وفشل على Linux بـ `exec format error`، والباكدجات المترجمة لكل منصة كل واحدة كانت هتحتاج pipeline إصدار خاص بيها، فالكود اللي بيتشغّل بـ Bun بقى نموذج التوزيع.

خريطة الـ `exports` بتاعت الباكدج بتكشف `src/sdk.ts` كنقطة الدخول البرمجية الموصوفة في [واجهة الـ Agent SDK](/arz/sdk). الإصدارات بتتعلّم بـ `v<version>` على GitHub؛ الـ CI بينشر لـ npm عن طريق النشر الموثوق (OIDC، مع provenance)، وبوابة النشر بتشغّل الـ typecheck ومجموعة الاختبارات الكاملة الأول.
