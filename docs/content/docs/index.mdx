title: Welcome
description: Pool your own agent CLI accounts and keep every session moving
---

tokenmaxxing is a CLI for people who run Claude Code (and Codex) on several of their own accounts. It watches usage quotas, swaps the active credential to the account with the most headroom before a limit hits, and keeps your sessions continuable across swaps.
