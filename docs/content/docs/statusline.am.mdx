tokenmaxxing የ Claude Code statusline ን በnative ያቀርባል (የአጠቃቀም feed ን tee እያደረገ)። የ design መርህ፦ ኮታ በቀለም ይሸከማል እንጂ በቁጥሮች አይደለም። አንድ መስመር፣ ለምሳሌ፦

```

```

- እያንዳንዱ window token የራሱ time-to-reset ነው፣ በተጠቀመ መቶኛ በተከታታይ አረንጓዴ-ወደ-ቢጫ-ወደ-ቀይ ramp ላይ የተቀባ (terminal ሲደግፈው truecolor፣ አለበለዚያ ወደ 256-color cube የተደረገ)። ramp ው ለ0 በንጹህ አረንጓዴ፣ በ75 ቢጫ፣ እና በ95 እና ከዚያ በላይ ቀይ ላይ ይያዛል፣ ስለዚህ የቆዩ የ severity ባንዶች እንደ ramp anchor ይተርፋሉ።
- የሞዴል ስሙ በተመሳሳይ ramp ላይ በ context-window fill ይቀባል።
- አረንጓዴ `◆` የንቁ መለያውን መስኮቶች ይመራል፤ እያንዳንዱ የተያዘ መለያ የራሱ cyan `◇` ያገኛል (reauth ካስፈለገው ቀይ `✗`)። መለያዎች በቀደመው ቀጣይ ዳግም ማስጀመሪያ ይደረደራሉ።
- በ-ሞዴል በእያንዳንዱ ብሎክ ውስጥ እንደ ባዶ የተቀባ የመጀመሪያ ፊደል መጀመሪያ ይመጣል፦ Fable `𝒇` ያቀርባል፤ ሌሎች ቤተሰቦች የከፍተኛ-ፊደል የመጀመሪያ ፊደላቸውን ይጠቀማሉ፣ ሁልጊዜ በ family-የተዛመደ።
- ያልተነካ የተያዘ መለያ አረንጓዴ `full` ያቀርባል። ካልታወቀ ዳግም ማስጀመሪያ ጋር የተለካ አጠቃቀም የተቀባ `?` ያቀርባል፣ እና በ gated ሞዴል ላይ ያልተለካ በ-ሞዴል ገደብ ያልተቀባ `𝒇?` ያቀርባል - ያልተለካ በጭራሽ ደህና መምሰል የለበትም።
- የዳግም ማስጀመሪያ countdownዎች ትልቁን አሃድ ብቻ ያሳያሉ፣ በጭራሽ "now" ወይም "0m" አይደለም፤ ቀጣይ ዳግም ማስጀመሪያ የሌለው መስኮት አረንጓዴ `0` ያቀርባል (እንደገና ባዶ)።
- የተገናኘ git worktree basename መስመሩን ይመራል፤ main checkout እዚያ ምንም አያቀርብም። ማወቁ filesystem ን ለ `.git` ፋይል ያነባል እና በጭራሽ git subprocess አያስነሳም።
- `NO_COLOR` ሲዋቀር፣ መስመሩ ወደ የተጣበቀ ቁጥራዊ ቅርጸት ይመለሳል (`2h5` ማለት በ2 ሰዓት ውስጥ ዳግም ይጀምራል፣ 5% ጥቅም ላይ ውሏል፤ `ctx 42` ለ context fill) - ያለ ቀለም፣ የተሟጠጠ መስኮት ትኩስ መምሰል የለበትም።
