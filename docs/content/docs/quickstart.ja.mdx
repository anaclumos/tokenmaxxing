title: クイックスタート
description: "tokenmaxxing をインストールし、現在のアカウントをインポートして、さらにプールする"
---

macOS または Linux 上で [Bun](https://bun.sh) と Claude Code が必要です。Bun で入れるか、すでに Nix / nix-darwin を使っているなら flake から入れられます。`init` の前に CLI を PATH に載せておいてください ([ビルドと配布](/ja/distribution) を参照):

```sh
bun add -g tokenmaxxing
tokenmaxxing init
```

Nix ユーザーは Bun のステップを `nix profile install github:anaclumos/tokenmaxxing` に置き換えるか、nix-darwin または Home Manager の設定で `programs.tokenmaxxing` を有効にしてください。

`init` は次の5つを行います。

1. すでにログイン済みのアカウントをアカウント #1 としてインポートします (別途 `adopt` コマンドはありません)。
2. `claude` スーパーバイザーのシムをインストールします。
3. Claude Code の `settings.json` に4つのエントリをインストールします。statusLine、Stop フック、StopFailure フック、SessionStart フック (加えて subagentStatusLine エントリ)。
4. スーパーバイザーの bin ディレクトリをシェル rc の PATH に追記します (冪等で、`# tokenmaxxing PATH` コメントで印を付けます)。本物の `claude` より前に PATH 上に置いてインターセプトする必要があります。
5. `tokenmaxxing check --if-due` を1ティックに1回 (`policy.checkIntervalMs`、デフォルトは60秒) 実行する定期チェックタイマーをインストールします (macOS では launchd エージェント、Linux では systemd ユーザータイマー)。チェックはライブアカウントの余裕に応じて、1から5ティックの間で自らペースを調整します。

シェルを再起動してから、アカウントを追加して始めます。

```sh
tokenmaxxing add        # もう1つのアカウントを分離環境でログインしてプールに追加する
claude                  # これまでどおり claude を使う
```

`tokenmaxxing` には `xx` というエイリアスもあります。引数なしの `tokenmaxxing` (または `xx`) は `status` を実行します。`switch` は明示的に指定する必要があります。
