tokenmaxxing Claude Code دی statusline نوں مقامی طور تے رینڈر کردا اے (نال ورتوں فیڈ نوں ٹی کردے ہوئے)۔ ڈزائن دا اصول: کوٹا رنگ وچ چُکیا جاندا اے، نمبراں وچ نئیں۔ اک لائن، مثال ولوں:

```
tm-wt-demo Fable 5 (high) +156/-23  ◆ 𝒇 2h 1d  ◇ 19h  ◇ 𝒇 2d  ◇ full  ✗ ?
```

- ہر ونڈو ٹوکن اوہدے ری سیٹ تیک دا ویلہ اے، جیہڑا ورتوں فیصد مطابق اک متواتر ہرے توں پیلے توں لال ریمپ تے رنگیا جاندا اے (جدوں ٹرمینل سہار سکے تاں truecolor، نہیں تاں 256 رنگ کیوب تے پُٹھ نال)۔ ریمپ 0 لئی خالص ہرے، 75 تے پیلے، تے 95 تے اوہدوں اُتے لال تے لنگر پاندا اے، سو پرانے شدت دے بینڈ ریمپ لنگراں وانگوں بچے رہندے نیں۔
- ماڈل دا ناں اوہو ریمپ تے سیاق ونڈو دی بھرائی مطابق رنگیا جاندا اے۔
- اک ہرا `◆` چالو اکاؤنٹ دیاں ونڈواں دی اگوائی کردا اے؛ ہر پارک کیتے اکاؤنٹ نوں اوہدا اپنا سیان `◇` مِلدا اے (جے اوہنوں مُڑ تصدیق چاہیدی ہووے تاں لال `✗`)۔ اکاؤنٹ سب توں چھیتی آن والے ری سیٹ مطابق ترتیب پاندے نیں۔
- فی ماڈل ہر بلاک وچ پہلاں اک ننگے رنگے ابتدائی اکھر وانگوں آندا اے: Fable `𝒇` بناندا اے؛ ہور خاندان اپنا وڈے اکھر والا پہلا حرف ورتدے نیں، ہمیشہ خاندان نال مِلایا۔
- اک اَن چھوہیا پارک کیتا اکاؤنٹ اک ہرا `full` بناندا اے۔ اک انجان ری سیٹ نال ماپی گئی ورتوں اک رنگیا `?` بناندی اے، تے اک گیٹ کیتے ماڈل تے اک اَن ماپی فی ماڈل حد اک بے رنگ `𝒇?` بناندی اے - اَن ماپی کدے وی محفوظ نئیں دِسنی چاہیدی۔
- ری سیٹ اُلٹی گنتیاں صرف سب توں وڈی اکائی ویکھاندیاں نیں، کدے "now" یا "0m" نئیں؛ اک ونڈو جیہدا کوئی آن والا ری سیٹ نہ ہووے اوہ اک ہرا `0` بناندی اے (مُڑ خالی)۔
- اک جُڑی git worktree دا بیس ناں لائن دی اگوائی کردا اے؛ اک مین چیک آؤٹ اوتھے کجھ نئیں بناندا۔ کھوج اک `.git` فائل لئی فائل سسٹم پڑھدی اے تے کدے کوئی git سب پروسیس شروع نئیں کردی۔
- `NO_COLOR` سیٹ ہون تے، لائن اک چمبڑی عددی صورت تے واپس آ جاندی اے (`2h5` دا مطلب 2 گھنٹیاں وچ ری سیٹ، 5% ورتیا؛ سیاق بھرائی لئی `ctx 42`) - رنگ بغیر، اک نکاسیا ونڈو تازہ نئیں دِسنا چاہیدا۔
