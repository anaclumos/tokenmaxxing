title: वैयक्तिक वापर आणि सेवा अटी
description: "तुमच्या मालकीची खाती, तुम्ही स्वतः चालवत असलेल्या सत्रांमध्ये आणि एजंट्समध्ये एकत्र करा"
---

tokenmaxxing तुमच्या मालकीची खाती, तुम्ही स्वतः चालवत असलेल्या सत्रांमध्ये आणि एजंट्समध्ये एकत्र करते. ती शब्दरचना मुद्दाम आहे: Anthropic तृतीय-पक्ष उत्पादनांना claude.ai लॉगिन किंवा claude.ai दर मर्यादा देऊ करण्याची परवानगी देत नाही, आणि त्यात Agent SDK वर बांधलेले एजंट्स समाविष्ट आहेत. पूल केलेला SDK पृष्ठभाग, किंवा त्यावर बांधलेले काहीही, तृतीय पक्षांना पाठवू नका. tokenmaxxing कोटा डेटासाठी OAuth पुन्हा-अंमलात आणण्याऐवजी किंवा API ट्रॅफिक प्रॉक्सी करण्याऐवजी मुद्दाम CLI-मध्यस्थ `/usage` मार्गावर देखील राहते: तो प्रॉक्सी नाही, आणि तो स्पर्श करणारे एकमेव OAuth एंडपॉइंट्स म्हणजे बदलादरम्यान वापरलेले प्रमाणित रीफ्रेश ग्रांट आणि एक केवळ-वाचन ओळख तपासणी (roles एंडपॉइंट) जी टोकन प्रत्यक्षात कोणत्या खात्याचे आहे याची पडताळणी करते.
