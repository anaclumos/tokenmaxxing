Paket npm mengirimkan kode sumber TypeScript, bukan sebuah build: bin `tokenmaxxing` menunjuk langsung ke `src/main.ts` dengan sebuah shebang Bun, dan Bun 1.2.6 atau yang lebih baru menjalankannya apa adanya. Itulah sebabnya Bun adalah persyaratan mutlak. Tidak ada biner terkompilasi berdasarkan desain: sebuah rilis awal mengirimkan satu biner macOS 61 MB ke setiap platform dan gagal di Linux dengan `exec format error`, dan paket terkompilasi per-platform masing-masing akan membutuhkan pipeline rilisnya sendiri, sehingga sumber-dijalankan-oleh-Bun menjadi model distribusinya.

Peta `exports` paket mengekspos `src/sdk.ts` sebagai titik masuk terprogram yang dijelaskan di [Permukaan Agent SDK](/id/sdk). Rilis ditandai `v<version>` di GitHub; CI menerbitkan ke npm melalui trusted publishing (OIDC, dengan provenance), dan gerbang penerbitan menjalankan typecheck dan seluruh rangkaian pengujian terlebih dahulu.

## Nix / nix-darwin

Pohon sumber yang sama juga merupakan flake. Model sumber-dijalankan-oleh-Bun tetap dipakai (via [bun2nix](https://github.com/nix-community/bun2nix) `writeBunApplication`) dan mengekspos:

| Keluaran | Tujuan |
|---|---|
| `packages.default` | `tokenmaxxing` + `xx` di PATH |
| `darwinModules.default` / `withOverlay` | nix-darwin: pasang CLI (timer pemeriksaan deklaratif opsional) |
| `homeManagerModules.default` | Home Manager di macOS atau Linux |
| `nixosModules.default` / `withOverlay` | instalasi sistem NixOS |

Sekali jalan tanpa memasang ke profil:

```sh
nix run github:anaclumos/tokenmaxxing -- help
```

nix-darwin (menambahkan overlay agar `pkgs.tokenmaxxing` ter-resolve):

```nix
{
  inputs.tokenmaxxing.url = "github:anaclumos/tokenmaxxing";
  # ...
  modules = [
    inputs.tokenmaxxing.darwinModules.withOverlay
    { programs.tokenmaxxing.enable = true; }
  ];
}
```

Atau set paket secara eksplisit (juga cocok dengan Home Manager):

```nix
{
  imports = [ inputs.tokenmaxxing.homeManagerModules.default ];
  programs.tokenmaxxing.enable = true;
  programs.tokenmaxxing.package = inputs.tokenmaxxing.packages.${pkgs.system}.default;
}
```

Nix hanya menaruh CLI di PATH. Impor akun, shim supervisor `claude` di PATH, hook `settings.json`, dan (secara default) timer pemeriksaan berkala tetap dari `tokenmaxxing init` — itu menyentuh kredensial dan pengaturan milik pengguna yang tidak seharusnya ditulis ulang oleh modul murni. Set `programs.tokenmaxxing.checkTimer.enable = true` hanya jika ingin Nix yang mengelola timer, bukan init.

Ketika `bun.lock` berubah, regenerasi ekspresi dependensi Nix:

```sh
bun run nix:bun   # writes bun.nix via bun2nix
```
