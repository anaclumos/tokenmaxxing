title: व्यक्तिगत उपयोग और सेवा की शर्तें
description: "अपने स्वामित्व वाले खातों को, उन सेशन और एजेंट में जिन्हें आप स्वयं चलाते हैं, पूल करें"
---

tokenmaxxing आपके स्वामित्व वाले खातों को, उन सेशन और एजेंट में जिन्हें आप स्वयं चलाते हैं, पूल करता है। वह शब्दावली जानबूझकर है: Anthropic तृतीय-पक्ष उत्पादों को claude.ai लॉगिन या claude.ai रेट सीमाएं प्रदान करने की अनुमति नहीं देता, और इसमें Agent SDK पर निर्मित एजेंट शामिल हैं। पूल की गई SDK सतह, या उस पर निर्मित किसी भी चीज़ को, तृतीय पक्षों को न भेजें। tokenmaxxing OAuth को फिर से लागू करने या API ट्रैफ़िक को प्रॉक्सी करने के बजाय कोटा डेटा के लिए जानबूझकर CLI-मध्यस्थ `/usage` पथ पर बना रहता है: यह एक प्रॉक्सी नहीं है, और यह केवल जिन OAuth एंडपॉइंट को छूता है वे हैं स्वैप के दौरान उपयोग किया जाने वाला मानक रिफ्रेश अनुदान और एक केवल-पढ़ने के लिए पहचान जांच (roles एंडपॉइंट) जो सत्यापित करती है कि एक टोकन वास्तव में किस खाते का है।
