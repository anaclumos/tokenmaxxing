---
title: การใช้งานส่วนตัวและข้อกำหนดในการให้บริการ
description: "รวมบัญชีที่คุณเป็นเจ้าของ ในเซสชันและ agent ที่คุณรันเอง"
---

tokenmaxxing รวมบัญชีที่คุณเป็นเจ้าของ ในเซสชันและ agent ที่คุณรันเอง ถ้อยคำนี้เป็นไปโดยเจตนา: Anthropic ไม่อนุญาตให้ผลิตภัณฑ์ของบุคคลที่สามเสนอการล็อกอิน claude.ai หรือลิมิตอัตราของ claude.ai และนั่นรวมถึง agent ที่สร้างบน Agent SDK ด้วย อย่าส่งมอบพื้นผิว SDK แบบพูล หรือสิ่งใดที่สร้างขึ้นบนมัน ให้แก่บุคคลที่สาม tokenmaxxing ยังคงอยู่บนเส้นทาง `/usage` ที่ผ่าน CLI สำหรับข้อมูลโควตาโดยเจตนา แทนที่จะสร้าง OAuth ขึ้นใหม่หรือทำพร็อกซีให้ทราฟฟิก API มันไม่ใช่พร็อกซี และ OAuth endpoint เดียวที่มันแตะคือ refresh grant มาตรฐานที่ใช้ระหว่างการสลับ และการตรวจสอบตัวตนแบบอ่านอย่างเดียว (roles endpoint) ที่ยืนยันว่า token เป็นของบัญชีใดจริงๆ
