---
title: 快速開始
description: "安裝 tokenmaxxing、匯入你而家用緊嘅帳戶，再集合多啲帳戶"
---

需要 [Bun](https://bun.sh) 同 Claude Code，喺 macOS 或者 Linux 上面。用 Bun 裝，或者如果你已經用緊 Nix / nix-darwin，就由 flake 裝。喺 `init` 之前要將 CLI 放上 PATH（睇[建置同分發](/yue/distribution)）：

```sh
bun add -g tokenmaxxing
tokenmaxxing init
```

用 Nix 嘅人就將 Bun 嗰步換成 `nix profile install github:anaclumos/tokenmaxxing`，又或者喺自己嘅 nix-darwin 或者 Home Manager 設定入面啟用 `programs.tokenmaxxing`。

`init` 會做五件事：

1. 將你已經登入咗嘅帳戶匯入做帳戶 #1（冇獨立嘅 `adopt` 指令）。
2. 安裝 `claude` 監督者 shim。
3. 喺 Claude Code 嘅 `settings.json` 入面安裝四個項目：statusLine、Stop hook、StopFailure hook 同 SessionStart hook（仲會加埋一個 subagentStatusLine 項目）。
4. 將監督者嘅 bin 目錄加去 shell rc 嘅 PATH（冪等，會用 `# tokenmaxxing PATH` 註解標記）。佢喺 PATH 上面必須排喺真正嘅 `claude` 前面，先至攔截到。
5. 安裝定期檢查計時器（macOS 上面係 launchd agent，Linux 上面係 systemd user timer），每一下 tick 行一次 `tokenmaxxing check --if-due`（`policy.checkIntervalMs`，預設 60 秒）；個檢查會按活躍帳戶嘅餘裕，喺一到五下 tick 之間自己調節節奏。

重新啟動 shell，然後加多啲帳戶就開始用：

```sh
tokenmaxxing add        # 用隔離方式登入多一個帳戶，再加入帳戶池
claude                  # 照舊咁用 claude
```

`tokenmaxxing` 亦都有個別名 `xx`。淨係行 `tokenmaxxing`（或者 `xx`）會執行 `status`；`switch` 就要明確噉打出嚟。
