description: உங்கள் சொந்த ஏஜென்ட் CLI கணக்குகளை ஒன்றிணைத்து ஒவ்வொரு அமர்வையும் தொடர்ந்து இயங்க வையுங்கள்
---

tokenmaxxing என்பது தங்களது பல சொந்த கணக்குகளில் Claude Code (மற்றும் Codex) இயக்குபவர்களுக்கான ஒரு CLI ஆகும். இது பயன்பாட்டு ஒதுக்கீடுகளை கண்காணித்து, ஒரு வரம்பு அடைவதற்கு முன்பு அதிக இடம் உள்ள கணக்கிற்கு செயலில் உள்ள சான்றுதலை மாற்றி, மாற்றங்கள் நெடுகிலும் உங்கள் அமர்வுகளைத் தொடரக்கூடியதாக வைத்திருக்கிறது.
