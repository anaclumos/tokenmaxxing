---
title: Интерфейс Agent SDK
description: "Свяжите пул с Claude Agent SDK в агентах, которых вы запускаете сами"
---

Программная точка входа пакета (`exports["."]` указывает на `src/sdk.ts`) связывает tokenmaxxing с Claude Agent SDK для агентов, которых вы строите на основе собственных объединённых аккаунтов. Ваше приложение должно работать под Bun (tokenmaxxing поставляется как исходный код на TypeScript и использует `bun:ffi`).

```ts
import { query } from "@anthropic-ai/claude-agent-sdk";
import { ensureBestAccount, pooledOptions, stopHookCheck } from "tokenmaxxing";

await ensureBestAccount();

for await (const message of query({
  prompt: "...",
  options: {
    ...pooledOptions(),
    hooks: { Stop: [{ hooks: [stopHookCheck] }] },
  },
})) {
}
```

Тело цикла получает поток сообщений. Сохраните идентификатор сессии из сообщения init, если хотите использовать `resume` при переключениях.

Agent SDK порождает подпроцесс claude на каждый `query()` и читает учётные данные один раз при порождении - никакого statusline, никакой горячей замены посреди запроса - поэтому интеграция управляется границами:

- `ensureBestAccount()` - это точно то же решение, что выполняют хуки и таймер CLI (пороги, давление темпа, пауза, весь код общий), никогда не упреждающее: сессия SDK никогда не может быть приостановлена для обратного отсчёта при исчерпании.
- `pooledOptions()` закрепляет `pathToClaudeCodeExecutable` за настоящим бинарником claude (никогда за оболочкой-супервизором) и предоставляет полную замену `env` с вычищенными всеми внешними переопределениями учётных данных. Он быстро завершается с ошибкой, если `CLAUDE_CONFIG_DIR` или `CLAUDE_SECURESTORAGE_CONFIG_DIR` установлены в окружении вашего приложения: в Linux переключение записало бы активные учётные данные туда, куда указывают эти переменные, тогда как вычищенный подпроцесс читает хранилище по умолчанию - тихая рассинхронизация с неверным аккаунтом.
- `stopHookCheck` заново выполняет решение на границах ходов; переключение, которое он совершает, вступает в силу при следующем порождении. Он ловит свои собственные ошибки (записывая в stderr и в лог), а не пробрасывает их дальше, потому что необработанное исключение хука может прервать агента, а прерывание хода из-за сломанной проверки переключения обходится дороже, чем продолжить на текущем аккаунте.

`sdk.ts` ничего не импортирует из самого Agent SDK; его значения структурно распределяются в опции SDK.
