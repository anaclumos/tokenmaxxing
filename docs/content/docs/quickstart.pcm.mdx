---
title: Quickstart
description: "Install tokenmaxxing, import the account wey you dey use now, and pool more"
---

E need [Bun](https://bun.sh) and Claude Code, for macOS or Linux. Install am with Bun, or from the flake if you don dey use Nix / nix-darwin already. Put the CLI for PATH before `init` (check [How dem dey build am and share am](/pcm/distribution)):

```sh
bun add -g tokenmaxxing
tokenmaxxing init
```

Nix users go replace the Bun step with `nix profile install github:anaclumos/tokenmaxxing`, or dem go enable `programs.tokenmaxxing` for dia nix-darwin or Home Manager config.

`init` dey do five things:

1. E dey import the account wey you don already login with as account #1 (no separate `adopt` command dey).
2. E dey install the `claude` supervisor shim.
3. E dey install four entries for Claude Code im `settings.json`: one statusLine, one Stop hook, one StopFailure hook, and one SessionStart hook (plus one subagentStatusLine entry).
4. E dey append the supervisor im bin directory go your shell rc im PATH (idempotent, wey dem mark with `# tokenmaxxing PATH` comment). E must sit ahead of the real `claude` for PATH make e fit intercept am.
5. E dey install one periodic check timer (launchd agent for macOS, systemd user timer for Linux) wey dey run `tokenmaxxing check --if-due` once per tick (`policy.checkIntervalMs`, 60 seconds by default); the check dey pace imself between one and five ticks based on the live account im headroom.

Restart your shell, then add more accounts and go:

```sh
tokenmaxxing add        # dey login one more account, for isolation, and pool am
claude                  # use claude as you dey always use am
```

`tokenmaxxing` get alias too as `xx`. Bare `tokenmaxxing` (or `xx`) dey run `status`; `switch` still dey explicit.
