tokenmaxxing est un CLI destiné aux personnes qui utilisent Claude Code (et Codex) sur plusieurs de leurs propres comptes. Il surveille les quotas d'utilisation, bascule les identifiants actifs vers le compte disposant de la plus grande marge avant qu'une limite ne soit atteinte, et permet à vos sessions de rester continuables au fil des basculements.
