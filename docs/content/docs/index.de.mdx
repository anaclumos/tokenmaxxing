---

tokenmaxxing ist ein CLI für Menschen, die Claude Code (und Codex) über mehrere eigene Konten betreiben. Es überwacht die Nutzungskontingente, wechselt die aktive Anmeldeinformation vor Erreichen eines Limits zu dem Konto mit dem meisten Spielraum und hält Ihre Sitzungen über Wechsel hinweg fortsetzbar.
