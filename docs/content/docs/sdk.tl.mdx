---
title: Ang Agent SDK surface
description: "Ipares ang pool sa Claude Agent SDK sa mga agent na ikaw mismo ang nagpapatakbo"
---

Ang programmatic entry ng package (ang `exports["."]` ay nakaturo sa `src/sdk.ts`) ay ipinapares ang tokenmaxxing sa Claude Agent SDK para sa mga agent na binubuo mo laban sa iyong sariling mga naka-pool na account. Dapat tumakbo ang iyong app sa ilalim ng Bun (naghahatid ang tokenmaxxing ng TypeScript source at gumagamit ng `bun:ffi`).

```ts
import { query } from "@anthropic-ai/claude-agent-sdk";
import { ensureBestAccount, pooledOptions, stopHookCheck } from "tokenmaxxing";

await ensureBestAccount();

for await (const message of query({
  prompt: "...",
  options: {
    ...pooledOptions(),
    hooks: { Stop: [{ hooks: [stopHookCheck] }] },
  },
})) {
}
```

Natatanggap ng katawan ng loop ang message stream; itabi ang session id mula sa init message kung gusto mong gumamit ng `resume` sa kabila ng mga pagpapalit.

Ang Agent SDK ay nag-spawn ng isang claude subprocess kada `query()` at binabasa ang mga credential nang minsan sa spawn - walang statusline, walang mid-query hot-swap - kaya't ang integration ay boundary-driven:

- Ang `ensureBestAccount()` ang eksaktong desisyon na pinapatakbo ng CLI hooks at timer (mga bar, pace pressure, cooldown, lahat ay shared code), hindi kailanman anticipatory: ang isang SDK session ay hindi kailanman maaaring i-pause para sa isang depleted countdown.
- Ang `pooledOptions()` ay nagpi-pin ng `pathToClaudeCodeExecutable` sa tunay na claude binary (hindi kailanman ang supervisor wrapper) at nagbibigay ng buong kapalit na `env` na may bawat ambient credential override na nalinis. Mabilis itong nabibigo kung ang `CLAUDE_CONFIG_DIR` o `CLAUDE_SECURESTORAGE_CONFIG_DIR` ay naka-set sa environment ng iyong app: sa Linux ay isusulat ng isang pagpapalit ang live credential kung saan nakaturo ang mga iyon habang binabasa ng scrubbed na subprocess ang default store, isang tahimik na wrong-account na desync.
- Muling pinapatakbo ng `stopHookCheck` ang desisyon sa mga turn boundary; ang isang pagpapalit na naisagawa nito ay magkakabisa sa susunod na spawn. Nahuhuli nito ang sarili nitong mga error (nagla-log sa stderr at sa log) sa halip na muling itapon, dahil ang isang hindi nahawakang hook exception ay maaaring makagambala sa agent, at ang pagpapahinto sa isang turn dahil sa isang sirang switch check ay mas mahal kaysa sa pagtitiis sa kasalukuyang account.

Walang ini-import ang `sdk.ts` mula sa Agent SDK mismo; ang mga halaga nito ay structural na kumakalat sa mga opsyon ng SDK.
