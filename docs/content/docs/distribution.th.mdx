---
title: การ build และการเผยแพร่
description: "ซอร์ส TypeScript บน npm รันด้วย Bun เผยแพร่พร้อม provenance"
---

แพ็กเกจ npm เผยแพร่ซอร์ส TypeScript ไม่ใช่ไฟล์ที่ build แล้ว: bin `tokenmaxxing` ชี้ตรงไปที่ `src/main.ts` ด้วย Bun shebang และ Bun 1.2.6 หรือใหม่กว่าจะรันมันได้เลย นั่นคือเหตุผลที่ Bun เป็นข้อกำหนดที่ต้องมี ไม่มีไบนารีที่คอมไพล์แล้วโดยตั้งใจ: รุ่นแรกๆ เคยเผยแพร่ไบนารี macOS ขนาด 61 MB ไฟล์เดียวไปยังทุกแพลตฟอร์ม และล้มเหลวบน Linux ด้วย `exec format error` อีกทั้งแพ็กเกจที่คอมไพล์แยกตามแพลตฟอร์มก็ต้องมี release pipeline ของตัวเองแต่ละอัน การรันซอร์สด้วย Bun จึงกลายเป็นโมเดลการเผยแพร่

แมป `exports` ของแพ็กเกจเปิดเผย `src/sdk.ts` เป็นจุดเข้าเชิงโปรแกรมตามที่อธิบายไว้ใน [หน้าตาของ Agent SDK](/th/sdk) รุ่นต่างๆ ถูกแท็กเป็น `v<version>` บน GitHub; CI เผยแพร่ไปยัง npm ผ่าน trusted publishing (OIDC พร้อม provenance) และด่านตรวจก่อนเผยแพร่จะรัน typecheck และชุดทดสอบทั้งหมดก่อน
