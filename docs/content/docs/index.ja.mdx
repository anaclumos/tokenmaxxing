tokenmaxxing は、複数の自分のアカウントで Claude Code (および Codex) を実行している人のための CLI です。使用量クォータを監視し、制限に達する前にアクティブな認証情報を最も余裕のあるアカウントへ切り替え、切り替えをまたいでセッションを継続可能に保ちます。
