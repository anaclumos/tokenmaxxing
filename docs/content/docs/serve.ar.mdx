---
title: "جسر Slack: xx serve"
description: "يشغّل xx serve جلسات Claude Code من خيوط Slack عبر وضع Socket Mode"
---

يشغّل `tokenmaxxing serve` خادم Slack محليًا عبر وضع Socket Mode، دون الحاجة إلى عنوان URL عام. الإعداد:

```sh
tokenmaxxing serve setup                    # يطبع بيان التطبيق، ويطلب الرمزين
tokenmaxxing serve link <channel-id> <repo> # يربط قناة بسحب مستودع
tokenmaxxing serve                          # يشغّل الخادم
```

أشِر إلى البوت في قناة مرتبطة فيفتح جلسة Claude Code لذلك الخيط، في سحب المستودع المرتبط. وتشغّل كل رسالة خيط استعلام `query()` واحدًا من Agent SDK مع `resume`، لا استعلام بثّ دائمًا أبدًا، بحيث يعيد `ensureBestAccount()` تقييم التجمّع في كل دور مفرد ويستطيع الخادم إعادة التشغيل دون فقدان الخيوط (سجلّات الخيوط دائمة؛ ويعيد الخادم الاشتراك بها عند بدء التشغيل).

سلوك جدير بالملاحظة:

- **البثّ**: تُبَثّ الردود أصليًا في Slack، مع بطاقات مهام للتفكير وتشغيل الأدوات، وشيفرة محاطة معروضة مع تمييز، وبطاقة "Turn" ختامية بالتكلفة والمدّة؛ وتُطوى جميع بطاقات الدور في كتلة خطة واحدة قابلة للتوسيع، بحيث يُقرأ الدور عادةً بوصفه رسالة واحدة: الردّ مع قائمة منسدلة واحدة لنشاطه (تفتح إعادة محاولة أثناء الدور أو إلحاق مرفوض رسالة تالية). وتحدّث استدعاءات TodoWrite بطاقة قائمة مراجعة واحدة ثابتة في مكانها.
- **الأذونات**: يكون `permissionMode` لكل رابط افتراضيًا `acceptEdits`؛ ويُدخِل `--yolo` (الاسم المستعار `--dangerous`) الرابطَ في `bypassPermissions`. والحوارات التفاعلية غير مسموحة في الأدوار المُمرَّرة، إذ لا يستطيع أحد الإجابة عنها عبر Slack، لذا يسأل النموذج نثرًا ويكون ردّك في الخيط هو الدور التالي. وتعلّمه مهارة إضافة مجمّعة أن يشير إلى مقدّم الطلب وينهي الدور عندما يحتاج إلى قرار.
- **أوامر الشرطة المائلة**: رسالة خيط يبدأ نصّها المُجرّد بـ `/` تعمل بوصفها أمر شرطة مائلة في claude. ويبتلع محرّر Slack الرسائل التي تبدأ بـ `/`، لذا استخدم صيغة الإشارة أوّلًا (`@bot /usage`) أو مسافة بادئة.
- **الاستئناف التلقائي عند حدّ الاستخدام**: عندما يبلغ كل حساب في التجمّع حدّه، يركن انقطاع قصير الرسالة ويعيد المحاولة في مكانها؛ أمّا الانقطاع الأطول فينشر إشعار انتظار ويستأنف الدور تلقائيًا فور تعافي التجمّع، ناجيًا من إعادة تشغيل الخادم. ولا يُطلب منك إعادة الإرسال إلا عند حدٍّ لا يُعرف له وقت تعافٍ.
- **الإغلاق اللطيف**: يستنزف SIGTERM/SIGINT العملَ الجاري: إذ تُسقَط الأدوار الجديدة بصوت مسموع، وتحصل الأدوار الجارية على ما يصل إلى 5 دقائق، وتعمل عملية claude الابنة منفصلة في مجموعة عملياتها الخاصة بحيث لا يستطيع Ctrl-C في الطرفية قتلها قبل أن يحفظ الاستنزاف الدور.
- **تنظيف الخيوط**: عندما تخبره بأن العمل قد انتهى، يستدعي النموذج أداة `finish_thread` داخل العملية؛ وبعد أن ينتهي الدور تمامًا، يُسقِط الخادم سجلّ الخيط ويلغي الاشتراك وينشر تأكيدًا واحدًا. وتبدأ إشارة جديدة جلسة جديدة.
- **نظافة الأخطاء**: تنشر أخطاء الأدوار نصًّا مقتضبًا مقتصرًا على الرسالة، لا أجسام أخطاء خام أبدًا.
