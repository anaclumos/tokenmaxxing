---
title: 誠實嘅限制
description: "集合式熱切換會帶嚟嘅取捨"
---

- **一個冷回合。** Prompt 快取係組織範圍嘅，所以喺新帳戶嘅第一個回合會重新上載一次上下文。
- **耗盡暫停打嗝。** 只有完全耗盡嘅帳戶池先會為咗倒數暫停 session;喺嗰一瞬間打嘅任何嘢都會唔見咗。
- **採用延遲。** 喺 macOS，切換之後 ~30 秒內嘅第一個回合仍然可能計落舊帳戶度;啲界線嘅餘裕會吸收佢。
- **共用嘅波及範圍。** 所有預設 profile 嘅 session 共用一個活躍憑證，所以一次切換會將佢哋全部一齊搬（每個就地採用）。
- **Linux 上面嘅明文憑證。** Claude Code 自己將 Linux 憑證儲存做 0600 明文檔案;tokenmaxxing 嘅泊存副本都係跟返同樣嘅做法。
