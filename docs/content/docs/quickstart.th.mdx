---
title: เริ่มต้นอย่างรวดเร็ว
description: "ติดตั้ง tokenmaxxing นำเข้าบัญชีปัจจุบันของคุณ และรวมบัญชีเพิ่มเข้าพูล"
---

ต้องใช้ [Bun](https://bun.sh) และ Claude Code บน macOS หรือ Linux. ติดตั้งด้วย Bun หรือจาก flake ถ้าคุณใช้ Nix / nix-darwin อยู่แล้ว โดยต้องนำ CLI ขึ้น PATH ก่อนรัน `init` (ดู [การ build และการเผยแพร่](/th/distribution)):

```sh
bun add -g tokenmaxxing
tokenmaxxing init
```

ผู้ใช้ Nix ให้แทนขั้นตอนของ Bun ด้วย `nix profile install github:anaclumos/tokenmaxxing` หรือเปิดใช้ `programs.tokenmaxxing` ใน config ของ nix-darwin หรือ Home Manager

`init` ทำห้าอย่าง:

1. นำเข้าบัญชีที่คุณเข้าสู่ระบบอยู่แล้วเป็นบัญชี #1 (ไม่มีคำสั่ง `adopt` แยกต่างหาก)
2. ติดตั้ง shim ของ supervisor สำหรับ `claude`
3. ติดตั้งสี่รายการใน `settings.json` ของ Claude Code ได้แก่ statusLine, Stop hook, StopFailure hook และ SessionStart hook (พร้อมกับรายการ subagentStatusLine)
4. เพิ่มไดเรกทอรี bin ของ supervisor เข้าไปใน PATH ของไฟล์ rc ของเชลล์คุณ (ทำซ้ำได้โดยไม่เปลี่ยนผล มีคอมเมนต์ `# tokenmaxxing PATH` กำกับไว้) มันต้องอยู่ก่อน `claude` ตัวจริงใน PATH เพื่อดักจับ
5. ติดตั้งตัวจับเวลาตรวจสอบเป็นระยะ (launchd agent บน macOS และ systemd user timer บน Linux) ที่รัน `tokenmaxxing check --if-due` ทุก 60 วินาที ส่วนตัวการตรวจสอบเองจะกำหนดจังหวะของมันไว้ระหว่างหนึ่งถึงห้านาทีจากพื้นที่เหลือของบัญชีที่ใช้งานอยู่

รีสตาร์ทเชลล์ของคุณ จากนั้นเพิ่มบัญชีและเริ่มใช้งานได้เลย:

```sh
tokenmaxxing add        # เข้าสู่ระบบอีกหนึ่งบัญชีแบบแยกส่วน แล้วรวมเข้าพูล
claude                  # ใช้ claude ได้เหมือนเดิม
```

`tokenmaxxing` มี alias เป็น `xx` ด้วย การพิมพ์ `tokenmaxxing` (หรือ `xx`) เปล่าๆ จะรัน `status` ส่วน `switch` ต้องระบุอย่างชัดเจนเสมอ
