---
title: Perintah
description: "Setiap perintah tokenmaxxing dan fungsinya"
---

| Perintah | Fungsinya |
|---|---|
| `tokenmaxxing init` | Impor akun saat ini, pasang supervisor, hook, dan statusline |
| `tokenmaxxing init --codex` | Sama untuk Codex: impor login, pasang supervisor codex dan hook Stop |
| `tokenmaxxing add` | Daftarkan akun tambahan (login terisolasi, dipanen ke dalam gabungan) |
| `tokenmaxxing add --codex` | Daftarkan akun Codex tambahan (login terisolasi) |
| `tokenmaxxing auth [sel \| --all]` | Autentikasi ulang akun yang tergabung di tempat. Tanpa argumen ia menampilkan gabungan dan menanyakan yang mana; sebuah selektor menargetkan satu akun dan memberi tahu email mana yang harus dipakai login; `--all` menelusuri setiap akun yang perlu-autentikasi-ulang satu per satu |
| `tokenmaxxing switch [sel]` | Berpindah ke akun terbaik (rakus, idempoten) atau paksa satu akun tertentu |
| `tokenmaxxing switch --codex [sel]` | Tukar gabungan Codex (berlaku saat codex berikutnya dimulai) |
| `tokenmaxxing ls` | Daftar akun yang tergabung |
| `tokenmaxxing status` | Akun dengan bilah penggunaan 5 jam / mingguan / per-model, aktif dan habis-sampai-reset |
| `tokenmaxxing status --ping` | Selain itu memberi ping setiap akun (satu permintaan haiku kecil masing-masing) sehingga semua pengatur waktu sesi 5 jam mulai sekarang, lalu mengambil sampel segar |
| `tokenmaxxing watch [seconds]` | Status langsung, dirender ulang setiap N detik (default 120, minimum 30; tidak pernah memberi ping) |
| `tokenmaxxing config [get\|set\|unset\|tidy]` | Konfigurasi efektif beserta sumbernya; sunting kunci bertitik; `tidy` memangkas kunci yang tidak dikenal |
| `tokenmaxxing check` | Evaluasi keputusan pertukaran sekali (inilah yang dijalankan pengatur waktu berkala) |
| `tokenmaxxing doctor` | Verifikasi bahwa supervisor dan entri pengaturan tetap ada |
| `tokenmaxxing rename [--codex] <sel> <label>` | Ganti label akun yang tergabung |
| `tokenmaxxing rm [--codex] <sel>` | Hapus sebuah akun (beserta kredensial yang diparkir) dari gabungan claude atau codex |
| `tokenmaxxing uninstall` | Hapus supervisor dan entri pengaturan (akun dan kredensial dipertahankan) |
