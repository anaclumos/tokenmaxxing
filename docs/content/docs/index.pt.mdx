description: Agrupe suas próprias contas de CLI de agentes e mantenha cada sessão em andamento
---

tokenmaxxing é uma CLI para quem usa Claude Code (e Codex) em várias contas próprias. Ela monitora as cotas de uso, troca a credencial ativa para a conta com mais folga antes que um limite seja atingido e mantém suas sessões continuáveis entre as trocas.
