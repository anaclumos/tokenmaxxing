title: statusline
description: "配額用顏色承載，一行，每個帳戶都睇得到"
---

tokenmaxxing 原生渲染 Claude Code 嘅 statusline（同時 tee 個用量資訊來源）。設計原則：配額用顏色承載，唔係用數字。一行,例如：

```
tm-wt-demo Fable 5 (high) +156/-23  ◆ 𝒇 2h 1d  ◇ 19h  ◇ 𝒇 2d  ◇ full  ✗ ?
```

- 每個窗口 token 係佢距離重設嘅時間，按已用百分比塗上一個連續嘅綠到黃到紅漸變（終端支援時用真彩色，否則就步進去 256 色立方體）。個漸變喺 0 錨定純綠，75 錨定黃，95 同以上錨定紅，所以舊嘅嚴重程度分帶得以以漸變錨點嘅形式保留。
- 模型名按同一個漸變嘅上下文窗口填充嚟塗色。
- 一個綠色 `◆` 引領活躍帳戶嘅窗口;每個泊存帳戶都有佢自己嘅青色 `◇`（如果需要重新認證就係紅色 `✗`）。帳戶按最早即將到嚟嘅重設排序。
- 每模型喺每個區塊排最先,做一個淨嘅塗色首字母：Fable 渲染做 `𝒇`;其他系列用佢哋轉大楷嘅首字母，永遠係系列配對嘅。
- 一個未被觸碰嘅泊存帳戶渲染做一個綠色 `full`。有量度到用量但係重設未知就渲染做一個塗色嘅 `?`，而一個被閘模型上面一個未量度嘅每模型上限就渲染做一個未塗色嘅 `𝒇?` - 未量度嘅永遠唔可以睇落好安全。
- 重設倒數只顯示最大嘅單位，永遠唔會係「now」或者「0m」;一個無即將到嚟重設嘅窗口渲染做一個綠色 `0`（又空咗）。
- 一個連結咗嘅 git worktree 嘅 basename 引領嗰行;一個主 checkout 喺嗰度咩都唔渲染。個偵測讀取檔案系統搵一個 `.git` 檔案，永遠唔會生成一個 git 子進程。
- 設定咗 `NO_COLOR` 嗰陣,嗰行會退回去一個黐埋嘅數字格式（`2h5` 意思係 2 小時後重設，已用 5%;`ctx 42` 代表上下文填充）- 無顏色嘅話，一個耗盡嘅窗口永遠唔可以睇落好新鮮。

子 agent 任務透過 claude 嘅 subagentStatusLine 表面攞到佢哋自己嘅面板行：每個活躍任務一行，系列名按嗰個任務嘅上下文填充嚟塗色。
