---
title: Mabilisang pagsisimula
description: "I-install ang tokenmaxxing, i-import ang iyong kasalukuyang account, at magdagdag pa sa pool"
---

Nangangailangan ng [Bun](https://bun.sh) at Claude Code, sa macOS o Linux. I-install gamit ang Bun, o mula sa flake kung gumagamit ka na ng Nix / nix-darwin. Ilagay ang CLI sa PATH bago ang `init` (tingnan ang [Build at pamamahagi](/tl/distribution)):

```sh
bun add -g tokenmaxxing
tokenmaxxing init
```

Pinapalitan ng mga gumagamit ng Nix ang hakbang na Bun ng `nix profile install github:anaclumos/tokenmaxxing`, o ini-enable nila ang `programs.tokenmaxxing` sa kanilang nix-darwin o Home Manager config.

May limang bagay na ginagawa ang `init`:

1. In-i-import ang account na kasalukuyan mong naka-log in bilang account #1 (walang hiwalay na `adopt` command).
2. Ini-install ang `claude` supervisor shim.
3. Nag-i-install ng apat na entry sa `settings.json` ng Claude Code: isang statusLine, isang Stop hook, isang StopFailure hook, at isang SessionStart hook (kasama ang isang subagentStatusLine entry).
4. Idinaragdag ang bin directory ng supervisor sa PATH ng iyong shell rc (idempotent, minarkahan ng isang `# tokenmaxxing PATH` na komento). Kailangan itong nasa unahan ng tunay na `claude` sa PATH upang ma-intercept ito.
5. Nag-i-install ng isang pana-panahong check timer (isang launchd agent sa macOS, isang systemd user timer sa Linux) na nagpapatakbo ng `tokenmaxxing check --if-due` isang beses kada tick (`policy.checkIntervalMs`, 60 segundo sa default); ang check mismo ang nagtatakda ng sarili nitong bilis sa pagitan ng isa at limang tick batay sa headroom ng live na account.

I-restart ang iyong shell, pagkatapos ay magdagdag ng higit pang mga account at magsimula:

```sh
tokenmaxxing add        # nagla-log in ng isa pang account, nang nakahiwalay, at ipinu-pool ito
claude                  # gamitin ang claude tulad ng dati
```

Ang `tokenmaxxing` ay may alias ding `xx`. Ang payak na `tokenmaxxing` (o `xx`) ay nagpapatakbo ng `status`; nananatiling explicit ang `switch`.
