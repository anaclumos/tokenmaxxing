title: خوش آمدید
description: حساب‌های عامل CLI خودتان را یکجا جمع کنید و هر نشست را در جریان نگه دارید
---

tokenmaxxing یک CLI برای کسانی است که Claude Code (و Codex) را روی چند حساب متعلق به خودشان اجرا می‌کنند. این ابزار سهمیه‌های مصرف را زیر نظر می‌گیرد، پیش از رسیدن به یک محدودیت، اعتبارنامه فعال را به حسابی که بیشترین فضای آزاد را دارد جابه‌جا می‌کند، و نشست‌های شما را در طول این جابه‌جایی‌ها قابل ادامه نگه می‌دارد.
