title: トラブルシューティングと FAQ
description: "よくある質問と、その背後にある診断"
---

**`claude` がスーパーバイズされていないようです。**
`tokenmaxxing doctor` を実行してください。シムは PATH 解決で優先される必要があります。シェル rc の `# tokenmaxxing PATH` 行が現在の bin ディレクトリを指し、本物の claude より前に位置していることを確認してください。`doctor` はまた、ラッパーを覆い隠す `alias claude=...` や `claude()` シェル関数、そして claude バイナリを絶対パスで起動するエイリアス (スーパーバイザーを完全にバイパスします) についても警告します。

**Codex で自動切り替えがまったく発火しません。**
codex は信頼するよう指示されていないフックをスキップします。codex を開き、`/hooks` を実行し、tokenmaxxing の Stop フックを信頼してください。信頼はフックのハッシュに紐づいて記録されるため、フックが編集されたら再付与が必要です。

**statusline でアカウントに赤い `✗` が表示されます。**
そのリフレッシュトークンが失効しています (取り消されたか、バックアップの裏でローテートされた)。`tokenmaxxing auth <sel>` を実行してその場で再認証してください。コマンドはどのメールでサインインするか伝え、サインイン先が別のアカウントになるログインは拒否します。

**なぜ最も残りクォータの多いアカウントに切り替えないのですか。**
それがクォータを失効させるリスクが最も高いアカウントではないからです。ターゲットは自身の週次ペースから最も遅れているアカウントです。すなわち残りパーセントを週次リセットまでの時間で割ったものです。残りが等しい場合は期限の早い順、期限が等しい場合は残りの多い順に帰着します。

**今切り替えたのに statusline がまだ古いアカウントを示しています。**
macOS では最大約30秒間、これは想定内です。実行中のセッションは、次の認証情報キャッシュのリフレッシュ時に入れ替えられた認証情報を採用します。使用量 tee はまさにこの理由で切り替え後45秒間抑制されます。

**`status --force` はコストがかかりますか。**
はい、意図的にです。各アカウントに最小限の計測 haiku リクエストを1回送り、すべての5時間セッションウィンドウが休眠したままにならずその瞬間に開始されるようにしてから、新しくサンプリングします。通常の `status` と `watch` は決して ping しません。`/usage` の読み取りは無料です。サーバーの使用量フィードは新しく開いたウィンドウを数秒から数分遅延させることがあるため、ping 直後のプローブはまだ ping 前の状態を示すことがあります。`status` は ping が失敗したふりをする代わりに注記を表示します。

**`/usage` プローブがアクティブアカウントでは何も返しませんでした。**
これは claude の既知の挙動です。内部の使用量フェッチが失敗またはレート制限されると、`/usage` はローカルのセッション統計のみをパーセンテージ行なしで表示します。tokenmaxxing はまさにこれを避けるために、アクティブアカウントを statusline のプッシュからサンプリングし、パーク済みのアカウントのみをプローブします。

**バックグラウンドの claude セッション。**
claude のバックグラウンドデーモンは、本物のバージョン付きバイナリを絶対パスで起動し、PATH シムをバイパスするため、バックグラウンドセッションはスーパーバイズされません。フックは依然として `settings.json` 経由で発火し、認証情報の採用と定期タイマーが切り替えをカバーしますが、マーカー駆動の再起動はありません。

**かつて何かが大量のプロセスを起動しました。今でも起こりうるのですか。**
スーパーバイザーは、まさにこの過去の障害 (古いラッパーが「本物の」claude として固定される) を防ぐ多層の再帰ガードを備えています。5レベルで中止する環境内の深さセンチネル、ディスク上の起動レート制限、tokenmaxxing 自身の bin ディレクトリに解決し直すあらゆる候補を拒否する realpath の識別チェック、そして設定された claude パスが存在しなくなったときの (静かな PATH スキャンではなく) ハード失敗です。`init` と `doctor` は、固定する前に `--version` を実行して候補が実際に claude であることを検証します。

**アンインストール。**
`tokenmaxxing uninstall` はスーパーバイザーシム、設定エントリ、定期タイマーを削除し、アカウントとパーク済みの認証情報はそのまま残します。自身のものと認識する statusline エントリのみを削除します。
