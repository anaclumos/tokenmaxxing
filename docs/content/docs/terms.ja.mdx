---
title: 個人利用と利用規約
description: "自分が保有するアカウントを、自分自身が実行するセッションやエージェントの中でプールする"
---

tokenmaxxing は、自分が保有するアカウントを、自分自身が実行するセッションやエージェントの中でプールします。この文言は意図的なものです。Anthropic はサードパーティ製品が claude.ai のログインや claude.ai のレート制限を提供することを許可しておらず、これには Agent SDK 上に構築されたエージェントも含まれます。プールされた SDK サーフェス、またはその上に構築されたものを、サードパーティに提供しないでください。tokenmaxxing はまた、OAuth を再実装したり API トラフィックをプロキシしたりする代わりに、クォータデータの取得には意図的に CLI 経由の `/usage` パスを使い続けます。これはプロキシではなく、触れる OAuth エンドポイントは、切り替え中に使われる標準のリフレッシュグラントと、トークンが実際にどのアカウントに属するかを検証する読み取り専用の識別チェック (roles エンドポイント) だけです。
