---
title: Mga Command
description: "Bawat command ng tokenmaxxing at kung ano ang ginagawa nito"
---

| Command | Ano ang ginagawa nito |
|---|---|
| `tokenmaxxing init` | I-import ang kasalukuyang account, i-install ang supervisor, mga hook, at statusline |
| `tokenmaxxing init --codex` | Pareho para sa Codex: i-import ang login, i-install ang codex supervisor at Stop hook |
| `tokenmaxxing add` | Magrehistro ng karagdagang account (nakahiwalay na login, aani papunta sa pool) |
| `tokenmaxxing add --codex` | Magrehistro ng karagdagang Codex account (nakahiwalay na login) |
| `tokenmaxxing auth [sel \| --all]` | Muling i-authenticate ang isang naka-pool na account nang nasa lugar. Inililista ng payak na anyo ang pool at nagtatanong kung alin; ang isang selector ay tumutukoy sa isang account at sinasabi kung aling email ang gagamitin sa pag-sign in; nililibot ng `--all` ang bawat account na nangangailangan ng reauth nang isa-isa |
| `tokenmaxxing switch [sel]` | Lumipat sa pinakamahusay na account (greedy, idempotent) o pilitin ang isang partikular |
| `tokenmaxxing switch --codex [sel]` | Ilipat ang Codex pool (magkakabisa sa susunod na pagsisimula ng codex) |
| `tokenmaxxing ls` | Ilista ang mga naka-pool na account |
| `tokenmaxxing status` | Mga account na may 5h / lingguhan / bawat-modelo na usage bar, aktibo at naubos-hanggang-reset |
| `tokenmaxxing status --force` | Karagdagang mag-ping sa bawat account (isang maliit na haiku request bawat isa) upang magsimula na ngayon ang lahat ng 5h session timer, pagkatapos ay kumuha ng sariwang sample |
| `tokenmaxxing watch [seconds]` | Live na status, muling ini-render tuwing N segundo (default 120, floor 30; hindi kailanman nag-ping) |
| `tokenmaxxing config [get\|set\|unset\|tidy]` | Epektibong config na may mga pinagmulan; i-edit ang mga dotted key; pinuputol ng `tidy` ang mga hindi kilalang key |
| `tokenmaxxing check` | Suriin ang desisyon sa pagpapalit nang isang beses (ito ang pinapatakbo ng pana-panahong timer) |
| `tokenmaxxing doctor` | Patunayan na nakaligtas ang supervisor at mga settings entry |
| `tokenmaxxing rename [--codex] <sel> <label>` | Palitan ang label ng isang naka-pool na account |
| `tokenmaxxing rm [--codex] <sel>` | Alisin ang isang account (kasama ang naka-park na credential nito) mula sa claude o codex pool |
| `tokenmaxxing uninstall` | Alisin ang supervisor at mga settings entry (pinananatili ang mga account at credential) |
